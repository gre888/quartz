|`b0`|截距 intercept|
|`b1`|斜率 coefficient|

# 三、Residual 殘差

模型預測：

```
真實值：100
預測值：90
```

殘差：

Residual=y−y^Residual = y-\hat y

所以：

```
100 - 90 = 10
```

### 重要

**Residual = 真實值 − 預測值**

不要跟：

```
預測值 − 真實值
```

搞混。

# 四、RSS / SSE / MSE

這一區非常容易考。

教材指出：

> RSS = Residual Sum of Squares（殘差平方和）  
> SSE = Sum of Squares Error（誤差平方和）  
> MSE = Mean Squared Error（均方誤差）  
> MSE 可以理解成把 RSS「平均化」。

## 1. RSS

RSS=∑(yi−y^i)2RSS=\sum(y_i-\hat y_i)^2

意思：

> **所有殘差平方加起來**

---

## 2. MSE

MSE=RSSnMSE=\frac{RSS}{n}

意思：

> **RSS 除以資料筆數**

所以：

```
RSS → 加總
MSE → 平均
```

### 考試超重要

|指標|意思|
|---|---|
|Residual|真實值 − 預測值|
|RSS|殘差平方的總和|
|SSE|誤差平方和|
|MSE|殘差平方的平均|

### 一句話記憶

> **RSS 是總和，MSE 是平均。**

# 六、L1 與 L2 正則化

這是非常重要的考試觀念。

主要目的：

> **避免 Overfitting 過擬合**

## 1. L1 Regularization → Lasso

Lasso：

```
from sklearn.linear_model import Lasso

model = Lasso(alpha=1.0)
```

L1 的特色：

> 可以讓某些 coefficient 變成 **0**

所以可以達到：

**Feature Selection 特徵選擇**

例如：

```
原本：

x1  x2  x3  x4  x5

最後：

x1  x2  x3=0  x4  x5=0
```

代表：

```
x3、x5 被模型捨棄
```

### 記憶

> **Lasso → L1 → 可以變 0 → 特徵選擇**

---

# 七、Ridge Regression

Ridge 使用：

> **L2 Regularization**

```
from sklearn.linear_model import Ridge

model = Ridge(alpha=1.0)
```

L2 不像 L1 那樣通常把係數直接壓到 0，而是：

> **把 coefficient 壓小**

例如：

```
原本：

10
8
5
3

Ridge：

4.2
3.8
2.1
1.5
```

### 記憶

> **Ridge → L2 → 把權重縮小**

---

# 八、Lasso vs Ridge

||Lasso|Ridge|
|---|---|---|
|Regularization|L1|L2|
|sklearn|`Lasso`|`Ridge`|
|係數|可變成 0|通常縮小但不為 0|
|特徵選擇|✅|❌|
|主要用途|特徵選擇＋防過擬合|防過擬合|

### ITS 考試記法

```
L1 → Lasso → 0
L2 → Ridge → 小
```

這組直接背起來。

# 十、Polynomial Regression 多項式迴歸

線性迴歸：

y=b0+b1xy=b_0+b_1x

Polynomial Regression 可以變成：

y=b0+b1x+b2x2+b3x3y=b_0+b_1x+b_2x^2+b_3x^3

例如：

```
x
x²
x³
```

讓模型可以處理：

> **非線性關係**

---

# 十一、PolynomialFeatures

sklearn：

```
from sklearn.preprocessing import PolynomialFeatures

poly = PolynomialFeatures(
    degree=2,
    include_bias=False
)

X_poly = poly.fit_transform(X)
```

---

## 1. degree

**最重要。**

教材指出：

```
degree=2
```

會產生：

```
1次
2次
```

如果：

```
x1, x2
```

則：

```
x1
x2
x1²
x1*x2
x2²
```

### 記法

```
degree=2 → 最高到平方
degree=3 → 最高到三次
```

---

# 十二、include_bias

```
PolynomialFeatures(
    degree=2,
    include_bias=False
)
```

### `True`

會加入：

```
1
```

也就是：

> 常數項 / bias / intercept column

### `False`

不加入全 1 欄。

教材特別提醒：

> 如果後面的模型本身已經有 intercept，例如 `LinearRegression` 預設有 intercept，通常設定 `include_bias=False`。

### 記法

```
include_bias=True
→ 加一欄 1

include_bias=False
→ 不加
```

---

# 十三、interaction_only

這個也很容易考。

```
PolynomialFeatures(
    degree=2,
    interaction_only=True
)
```

### False 預設

會有：

```
x1²
x2²
x1*x2
```

### True

只保留：

```
x1*x2
```

不包含：

```
x1²
x2²
```

教材就是這樣區分 `interaction_only=True/False`。

### 超好記

> `interaction_only=True` → **只要交互作用，不要平方**

# 十九、max_features

這個非常容易搞錯。

假設：

```
30 個特徵
max_features=6
```

不是：

> 每棵樹只使用 6 個特徵 ❌

而是：

> **每個節點切分時，隨機抽 6 個特徵來競爭。** ✅

教材特別強調這一點。

### 記法

```
n_estimators
→ 有幾棵樹

max_features
→ 每個節點切分時考慮多少特徵
```

---

# 二十、max_features="sqrt"

教材的例子：

```
25 個特徵
√25 = 5
```

所以：

```
max_features="sqrt"
```

大致表示每次選：

```
√特徵數
```

例如：

```
25 → 5
```

# 二十二、min_impurity_decrease

這個參數控制：

> **節點要改善多少，才允許繼續切分。**

例如：

```
RandomForestRegressor(
    min_impurity_decrease=0.01
)
```

教材的概念是：

```
改善量 Δ >= 0.01
```

才允許切分。

如果：

```
Δ < 0.01
```

就停止切分，變成葉節點。

# 二十三、Random Forest 必背整理

|參數|意思|
|---|---|
|`n_estimators`|樹的數量|
|`max_features`|每個節點切分時考慮的特徵數|
|`max_features="sqrt"`|特徵數開根號|
|`n_jobs`|CPU 平行運算|
|`n_jobs=-1`|使用所有可用 CPU|
|`min_impurity_decrease`|最低改善幅度|

### 一句話

> **樹有幾棵 → n_estimators；每次切分看幾個特徵 → max_features；CPU → n_jobs。**

# 二十四、Gradient Boosting

Gradient Boosting 的核心概念：

> **一棵一棵建立模型，後面的模型修正前面的錯誤。**

可以想像：

```
第一棵樹
   ↓
產生錯誤
   ↓
第二棵樹修正
   ↓
第三棵樹再修正
   ↓
……
   ↓
最後組合
```

教材有獨立的 Gradient Boosting 章節。

### 和 Random Forest 的概念差異

```
Random Forest
→ 很多樹
→ 各棵樹較獨立
→ 最後整合

Gradient Boosting
→ 一棵接一棵
→ 後面的修正前面的錯誤
```
