# Step 4：缺失值補值 Imputation

## Age → 中位數

```
age_median = df_clean['Age'].median()

df_clean['Age'].fillna(age_median, inplace=True)
```

### 核心

```
median()
```

取得中位數。

```
fillna()
```

填補缺失值。

所以：

```
df['Age'].fillna(df['Age'].median())
```

就是：

> Age 缺失 → 用 Age 的中位數補。

---

## Embarked → 眾數

```
embarked_mode = df_clean['Embarked'].mode()[0]

df_clean['Embarked'].fillna(embarked_mode, inplace=True)
```

### `mode()[0]`

`mode()` 找出眾數。

例如：

```
S 出現 644 次
C 出現 168 次
Q 出現 77 次
```

所以：

```
mode()[0]
```

得到：

```
S
```

---

### 考試記憶

```
數值型缺失
→ 常用 median

類別型缺失
→ 常用 mode
```

# Step 5：異常值 Outliers

你的例子是：

```
Fare
```

先畫 Boxplot：

```
sns.boxplot(x=df_clean['Fare'])
```

---

## IQR 方法

```
Q1 = df_clean['Fare'].quantile(0.25)
Q3 = df_clean['Fare'].quantile(0.75)

IQR = Q3 - Q1
```

公式：

```
IQR = Q3 - Q1
```

上界：

```
upper_bound = Q3 + 1.5 * IQR
```

下界：

```
lower_bound = Q1 - 1.5 * IQR
```

---

## 找出異常值

```
outliers = df_clean[
    (df_clean['Fare'] < lower_bound) |
    (df_clean['Fare'] > upper_bound)
]
```

意思：

```
Fare < 下界
OR
Fare > 上界
```

---

# Clipping 蓋帽法

你的程式最後使用：

```
df_clean['Fare'] = df_clean['Fare'].clip(
    lower=0,
    upper=upper_bound
)
```

意思：

```
小於 0
→ 變成 0

大於 upper_bound
→ 變成 upper_bound

正常範圍
→ 保持原值
```

可以想成：

```
        upper_bound
             ↓
─────────────┐
             │
正常資料     │
             │
─────────────┘
             ↑
             0
```

## ① 提取 Title

```
df_clean['Title'] = df_clean['Name'].str.extract(

```

### 正規表達式

```
r' ([A-Za-z]+)\.'
```

主要意思：

```
空格
↓
英文
↓
句點
```

例如：

```
Mr.
Mrs.
Miss.
Dr.
```

---

## Rare

把很少見的稱謂統一：

```
df_clean['Title'] = df_clean['Title'].replace(

```

例如：

```
Captain

```

統一成：

```
Rare
```

## Mlle、Ms → Miss

```
df_clean['Title'] = df_clean['Title'].replace(

)
```

---

## Mme → Mrs

```
df_clean['Title'] = df_clean['Title'].replace(
    'Mme',
    'Mrs'

```

# ② FamilySize

```
df_clean['FamilySize'] = (
    df_clean['SibSp']
    + df_clean['Parch']
    + 1
)
```

公式：

```
FamilySize = SibSp + Parch + 1
```

為什麼 +1？

因為：

```
SibSp = 兄弟姊妹 + 配偶
Parch = 父母 + 子女
自己 = 1
```

所以：

```
家庭大小
=
兄弟姊妹/配偶
+
父母/子女
+
自己
```

---

# ③ IsAlone

```
df_clean['IsAlone'] = 0

df_clean.loc[
    df_clean['FamilySize'] == 1,
    'IsAlone'
] = 1
```

意思：

```
FamilySize == 1
→ IsAlone = 1

其他
→ IsAlone = 0
```

也就是：

```
1 = 獨自一人
0 = 不是獨自一人
```

# Step 7：Encoding 特徵編碼

機器學習模型通常不能直接處理：

```
male
female

S
C
Q

Mr
Mrs
Miss
```

所以要轉換。

---

# Sex → Label Encoding

```
from sklearn.preprocessing import LabelEncoder

le = LabelEncoder()

df_clean['Sex'] = le.fit_transform(df_clean['Sex'])
```

例如：

```
female → 0
male   → 1
```

---

### `fit_transform()` 是什麼？

可以拆成：

```
le.fit()
```

學習資料中的類別。

再：

```
le.transform()
```

把類別轉成數字。

所以：

```
fit_transform()
```

就是兩步合在一起。

---

# Embarked、Title → One-Hot Encoding

```
df_clean = pd.get_dummies(
    df_clean,
    columns=['Embarked', 'Title'],
    drop_first=True
)
```

例如：

```
Embarked

S
C
Q
```

可能轉成：

```
Embarked_Q
Embarked_S
```

---

## `drop_first=True`

假設：

```
Sex
female
male
```

如果已經知道：

```
male = 0
```

那就不需要再建立兩個欄位。

可以少留一個欄位。

---

## True / False

新版 Pandas 有時候：

```
pd.get_dummies()
```

會得到：

```
True
False
```

如果老師希望：

```
1
0
```

可以：

```
df = pd.get_dummies(
    df,
    columns=['Embarked', 'Title'],
    drop_first=True,
    dtype=int
)
```

這樣：

```
True  → 1
False → 0
```

# Step 8：Scaling 特徵縮放

使用：

```
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
```

然後：

```
df_clean[['Age', 'Fare']] = scaler.fit_transform(
    df_clean[['Age', 'Fare']]
)
```

---

## StandardScaler 做什麼？

把資料轉成接近：

```
平均值 = 0
標準差 = 1
```

例如原本：

```
Age
22
38
26
35
```

經過 StandardScaler：

```
-0.56
 0.65
-0.26
 0.42
```

---

### 為什麼要 Scaling？

因為不同特徵的數值範圍可能差很多。

例如：

```
Age
0 ~ 80

Fare
0 ~ 500
```

縮放後比較容易讓某些機器學習演算法處理。

# ⭐ 這份程式最重要的考試重點

可以直接記這張：

|Step|名稱|主要程式|功能|

|2|檢查|`shape` / `info()` / `describe()`|了解資料|

# ⭐ 最後把整份程式想成一句話

```
CSV
 ↓

 ↓
檢查資料
 ↓
刪掉不要的欄位
 ↓
補缺失值
 ↓
處理異常值
 ↓
建立新特徵
 ↓
文字轉數字
 ↓
數值標準化
 ↓
得到可以交給 Machine Learning 的資料
```

其中最核心的觀念是：

> **原始資料通常不能直接拿去做機器學習，要先經過 Data Preprocessing。**

另外有一個實務上很重要的地方：你這份 `preprocess_titanic()` 把 `median`、`mode`、IQR 和 `StandardScaler` 都直接從「傳入的資料」計算。**如果之後分成 train/test 做真正的模型訓練，應該只用 train 資料 `fit`，再對 test 資料 `transform`，避免資料洩漏（data leakage）。**
