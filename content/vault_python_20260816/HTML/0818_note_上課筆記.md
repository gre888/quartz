# HTML 課程重點筆記

> 日期：2026-08-18  
> 範圍：文字格式、換行與預格式文字、`span`、`time`、清單、超連結、頁內連結、相對路徑、圖片與響應式圖片

## 1. HTML 基本結構

```html
<!DOCTYPE html>
<html lang="zh-Hant">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>網頁標題</title>
</head>
<body>
  網頁中看得到的內容
</body>
</html>
```

- `<!DOCTYPE html>`：宣告文件使用 HTML5。
- `<html>`：整份 HTML 文件的根元素。
- `<head>`：放編碼、標題、CSS 等網頁設定。
- `<meta charset="UTF-8">`：避免繁體中文顯示成亂碼。
- `<body>`：放使用者實際看得到的內容。
- 多數標籤必須成對出現，例如 `<p>...</p>`。
- `<br>`、`<img>`、`<meta>` 是空元素，不需要結束標籤。

## 2. 文字格式標籤

| 標籤 | 用途 | 說明 |
|---|---|---|
| `<b>` | 粗體 | 只有視覺效果，沒有特別語意 |
| `<strong>` | 重要文字 | 預設通常為粗體，具有「重要」語意 |
| `<i>` | 斜體 | 常用於術語、外文或特殊語氣 |
| `<em>` | 強調文字 | 預設通常為斜體，具有「強調」語意 |
| `<mark>` | 標記 | 類似螢光筆效果 |
| `<u>` | 加底線 | 表示非文字性的註記；純裝飾通常建議用 CSS |
| `<s>` | 刪除線 | 表示內容已不正確或不再適用 |
| `<del>` | 刪除內容 | 表示文件中被刪除的內容，具有語意 |
| `<sup>` | 上標 | 例如次方、註腳 |
| `<sub>` | 下標 | 例如化學式 |
| `<small>` | 小字 | 附註、版權等次要文字 |

```html
<p>
  <strong><mark>重要內容</mark></strong><br>
  水的化學式是 H<sub>2</sub>O，2<sup>3</sup> = 8。<br>
  原價 <s>1000 元</s>，特價 800 元。
</p>
```

### `<b>` 與 `<strong>` 的差別

- `<b>`：只想讓文字看起來粗體。
- `<strong>`：內容本身很重要，瀏覽器通常也顯示為粗體。

### `<i>` 與 `<em>` 的差別

- `<i>`：表現不同語氣、術語或外文。
- `<em>`：強調句子中的某段內容。

### 使用 `<span>` 搭配 CSS

`<span>` 是行內容器，本身沒有特殊外觀，適合選取一小段文字套用 CSS。

```html
<span style="font-weight: bold;">粗體文字</span>
<span style="background-color: yellow;">標記文字</span>
<span style="text-decoration: line-through;">刪除線</span>
<span style="text-decoration: underline;">底線</span>
```

若樣式會重複使用，應改用 class：

```html
<style>
  .note {
    color: blue;
    background-color: antiquewhite;
  }
</style>

<span class="note">這是一段註釋</span>
```

- `id`：同一頁面中應保持唯一，例如 `id="mark1"`。
- `class`：可以套用到多個元素，例如 `class="note"`。

## 4. 換行與保留原始排版

### `<br>`：單純換行

```html
<p>
  春眠不覺曉，<br>
  處處聞啼鳥。<br>
  夜來風雨聲，<br>
  花落知多少？
</p>
```

### `<pre>`：保留空白與換行

```html
<pre>
void main()
{
  printf("Hello, world!\n");
}
</pre>
```

一般 HTML 會把連續空白合併成一個空白；`<pre>` 會保留原始空格、縮排和換行，常用於程式碼或詩詞。若是程式碼，語意更完整的寫法是：

```html
<pre><code>print("Hello, world!")</code></pre>
```

## 5. 日期與時間：`<time>`

```html
<p>校慶日期為 <time datetime="2025-10-25">10 月 25 日</time></p>
<p>進場時間為 <time datetime="08:00">早上八點</time></p>
```

- 標籤中間：顯示給使用者看的文字。
- `datetime`：提供電腦可讀的標準日期或時間。

### JavaScript 動態時鐘

```html
<time id="clock"></time>

<script>
  function updateClock() {
    const now = new Date();
    const clock = document.getElementById("clock");
    clock.textContent = now.toLocaleTimeString();
    clock.dateTime = now.toISOString();
  }

  updateClock();
  setInterval(updateClock, 1000);
</script>
```

- `new Date()`：取得現在日期與時間。
- `textContent`：設定畫面顯示內容。
- `toLocaleTimeString()`：依使用者地區格式顯示時間。
- `setInterval(..., 1000)`：每 1000 毫秒更新一次。

## 6. 清單

### 無序清單：`ul`、`li`

```html
<ul>
  <li>射雕英雄傳</li>
  <li>神雕俠侶</li>
</ul>
```

常見項目符號：

```html
<ul style="list-style-type: disc;">...</ul>
<ul style="list-style-type: circle;">...</ul>
<ul style="list-style-type: square;">...</ul>
```

也可以使用圖片作為項目符號：

```html
<ul style="list-style-image: url('images/icon.png');">
  <li>第一項</li>
</ul>
```

### 有序清單：`ol`、`li`

```html
<ol type="A" start="5">
  <li>半生緣</li>
  <li>傾城之戀</li>
</ol>
```

- `type="1"`：數字。
- `type="A"` / `type="a"`：英文大寫／小寫。
- `type="I"` / `type="i"`：羅馬數字大寫／小寫。
- `start="5"`：從第 5 個編號開始。

也可使用 CSS：

```html
<ol style="list-style-type: decimal-leading-zero;">...</ol>
<ol style="list-style-type: lower-alpha;">...</ol>
<ol style="list-style-type: upper-roman;">...</ol>
```

`type` 屬性可快速設定基本類型；較完整的外觀控制建議使用 CSS 的 `list-style-type`。

### 巢狀清單

子清單應放在父項目的 `<li>` 裡面：

```html
<ul>
  <li>金庸作品
    <ol type="A">
      <li>射雕英雄傳</li>
      <li>神雕俠侶</li>
    </ol>
  </li>
</ul>
```

### 說明清單：`dl`、`dt`、`dd`

```html
<dl>
  <dt>黑面琵鷺</dt>
  <dd>候鳥名稱的詳細說明。</dd>

  <dt>赤腹鷹</dt>
  <dd>另一個名詞的詳細說明。</dd>
</dl>
```

- `<dl>`：說明清單。
- `<dt>`：名詞或標題。
- `<dd>`：名詞的描述。

相較於用多個 `<div>` 模擬，`dl`、`dt`、`dd` 的語意更明確。

## 7. 超連結：`<a>`

基本語法：

```html
<a href="pre.html">開啟另一個網頁</a>
```

### 常見 `href` 寫法

```html
<a href="pre.html">站內頁面</a>
<a href="https://www.google.com.tw/">外部網站</a>
<a href="poem.rar" download>下載檔案</a>
<a href="mailto:service@example.com">寄送電子郵件</a>
```

### `target` 屬性

| 寫法 | 效果 |
|---|---|
| 不寫 target | 在目前頁面開啟 |
| `target="_self"` | 在目前頁面開啟 |
| `target="_blank"` | 在新分頁或新視窗開啟 |
| `target="名稱"` | 在指定名稱的分頁／視窗開啟；相同名稱可重複使用同一個瀏覽環境 |

外部連結若用 `_blank`，可加上安全設定：

```html
<a href="https://www.apple.com/tw/"
   target="_blank"
   rel="noopener noreferrer">
  在新分頁開啟 Apple 網站
</a>
```

### 用 JavaScript 控制小視窗

```html
<a href="pre.html"
   onclick="window.open(this.href, 'test2', 'width=600,height=400'); return false;">
  開啟 600 × 400 視窗
</a>
```

`return false` 可避免瀏覽器在執行 `window.open()` 後又照原本連結跳轉。瀏覽器也可能基於安全政策阻擋彈出視窗。

> `ftp://` 連結在現代主流瀏覽器通常已不再直接支援，不建議作為一般網頁連結方案。

## 8. 頁內連結（錨點）

```html
<ul id="list">
  <li><a href="#bird1">黑面琵鷺</a></li>
  <li><a href="#bird2">赤腹鷹</a></li>
</ul>

<h2 id="bird1">黑面琵鷺</h2>
<p>內容…… <a href="#list">回到清單</a></p>

<h2 id="bird2">赤腹鷹</h2>
<p>內容…… <a href="#list">回到清單</a></p>
```

- `id="bird1"`：設定頁面中的目的地。
- `href="#bird1"`：跳到同頁面中該 id 的位置。
- `#` 表示頁面內的片段識別名稱。
- 同一頁面的 `id` 不可重複。

## 9. 絕對路徑、相對路徑與 `<base>`

### 絕對網址

```html
<a href="https://www.momoshop.com.tw/main/Main.jsp">momo 首頁</a>
```

包含通訊協定、網域和完整路徑，可以直接指出資源位置。

### 相對路徑

```html
<a href="pre.html">同一資料夾</a>
<img src="images/icon.png" alt="圖示">
<a href="../index.html">上一層的 index.html</a>
```

| 寫法 | 意義 |
|---|---|
| `pre.html` | 目前資料夾中的檔案 |
| `images/icon.png` | 目前資料夾下的 images 子資料夾 |
| `../index.html` | 上一層資料夾中的檔案 |
| `/images/icon.png` | 從網站根目錄開始 |

### `<base>`：設定相對網址的基準

```html
<head>
  <base href="https://www.momoshop.com.tw/">
</head>
<body>
  <a href="main/Main.jsp">momo 首頁</a>
  <a href="categories/2900000000">momo 家電</a>
</body>
```

有了 `<base>` 後，頁面內所有相對網址都會以該網址為基準。每份文件只能有一個 `<base>`，而且必須放在 `<head>` 內。它也會影響圖片、CSS、JavaScript 和頁內連結的解析，因此要謹慎使用。

## 10. 圖片：`<img>`

```html
<img src="rose.jpg" width="200" alt="紅玫瑰">
```

| 屬性 | 用途 |
|---|---|
| `src` | 圖片檔案的位置 |
| `alt` | 圖片無法顯示時的替代文字，也有助於無障礙閱讀 |
| `width` | 圖片寬度，可用像素數字或百分比 |
| `height` | 圖片高度 |

### 圖片比例

```html
<!-- 只設定寬度，瀏覽器會依比例調整高度 -->
<img src="rose.jpg" width="200" alt="紅玫瑰">

<!-- 同時指定寬高可能讓圖片變形 -->
<img src="rose.jpg" width="200" height="100" alt="紅玫瑰">
```

實務上可使用 CSS 製作自適應圖片：

```html
<img src="rose.jpg" alt="紅玫瑰" class="responsive-image">

<style>
  .responsive-image {
    max-width: 100%;
    height: auto;
  }
</style>
```

## 11. 響應式圖片：`srcset` 與 `sizes`

```html
<img
  srcset="rose_400w.jpg 400w,
          rose_600w.jpg 600w,
          rose_800w.jpg 800w"
  sizes="50vw"
  src="rose_800w.jpg"
  alt="紅玫瑰">
```

- `srcset`：列出不同寬度的圖片候選檔。
- `400w`、`600w`、`800w`：告訴瀏覽器各圖片的實際寬度。
- `sizes="50vw"`：告訴瀏覽器圖片顯示寬度約為視窗寬度的 50%。
- `src`：不支援 `srcset` 時的備用圖片。
- 瀏覽器會依螢幕大小、解析度與網路狀況選擇適合的圖片。

較常見的條件寫法：

```html
<img
  srcset="rose_400w.jpg 400w,
          rose_800w.jpg 800w"
  sizes="(max-width: 600px) 100vw, 50vw"
  src="rose_800w.jpg"
  alt="紅玫瑰">
```

意思是：螢幕不超過 600px 時，圖片約占整個視窗寬度；其餘情況約占一半。

## 12. 今天最容易考、最容易寫錯的地方

1. `<strong>`、`<em>` 有語意；`<b>`、`<i>` 主要是外觀或特殊語氣。
2. `<br>` 只負責換行；`<pre>` 會保留空白、縮排和換行。
3. `id` 原則上不可重複；`class` 可以重複使用。
4. `<ul>` 是無序清單，`<ol>` 是有序清單，項目都用 `<li>`。
5. `<dl>` 裡使用 `<dt>` 表示名詞、`<dd>` 表示說明。
6. `target="_blank"` 會開新分頁；外部連結建議加 `rel="noopener noreferrer"`。
7. `href="#名稱"` 會跳到同頁面具有相同 `id` 的元素。
8. `../` 表示上一層資料夾；開頭 `/` 表示網站根目錄。
9. `<base>` 會影響整份網頁的相對路徑，不只是超連結。
10. `<img>` 應寫有意義的 `alt`；只設定寬度通常較不容易讓圖片變形。
11. `srcset` 提供圖片候選檔；`sizes` 描述圖片預計占用的版面寬度。
12. HTML 標籤必須正確巢狀，`<head>` 與 `<body>` 不可互相混放內容。

## 13. 綜合練習範例

```html
<!DOCTYPE html>
<html lang="zh-Hant">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>花卉介紹</title>
  <style>
    body {
      font-family: Arial, "Microsoft JhengHei", sans-serif;
      line-height: 1.7;
    }

    .note {
      color: #075985;
      background-color: #e0f2fe;
    }

    img {
      max-width: 100%;
      height: auto;
    }
  </style>
</head>
<body>
  <h1 id="top">花卉介紹</h1>

  <ul>
    <li><a href="#rose">玫瑰</a></li>
    <li><a href="#lily">百合</a></li>
  </ul>

  <h2 id="rose">玫瑰</h2>
  <img
    srcset="rose_400w.jpg 400w, rose_800w.jpg 800w"
    sizes="(max-width: 600px) 100vw, 50vw"
    src="rose_800w.jpg"
    alt="一朵紅玫瑰">
  <p><strong>玫瑰</strong>常被用來表達情感。</p>
  <p><a href="#top">回到頁首</a></p>

  <h2 id="lily">百合</h2>
  <img src="lily.jpg" width="300" alt="白色百合花">
  <p><span class="note">百合的花形優雅。</span></p>
  <p><a href="#top">回到頁首</a></p>

  <p>更新日期：<time datetime="2026-08-18">2026 年 8 月 18 日</time></p>
</body>
</html>
```

## 14. 原始練習檔的修正提醒

- `<head>` 應以 `</head>` 正確結束，之後再寫 `<body>`。
- 顯示於頁面的 `<time id="clock">` 應放進 `<body>`，不要放在 `<head>`。
- 文件只需要一組 `<!DOCTYPE html>`、`<html>`、`<head>` 和 `<body>`。
- 不要在 `<h2>` 關閉後又多寫一次 `</h2>`。
- 連結到 `pre.html` 時，檔名必須與實際檔案完全相同；課程附件是 `pre(1).html`，若未改名，連結會找不到。
- 只寫 `<a href="poem.rar">` 可能由瀏覽器自行決定開啟或下載；若明確希望下載，可加 `download`。
- 使用 `window.open()` 時加上 `return false`，可避免同時觸發原連結的預設跳轉。
