
# HTML 0817 上課筆記

> 本筆記依照今日課堂的 HTML 範例整理，包含基本結構、文字與段落、區塊元素、HTML5 語意化標籤、CSS 樣式、圖片、滑鼠事件，以及完整網頁版面。

## 一、HTML 文件基本結構

```html
<!DOCTYPE html>
<html lang="zh-Hant">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的網頁</title>
  </head>
  <body>
    Hello, world!
  </body>
</html>
```

| 語法 | 說明 |
|---|---|
| `<!DOCTYPE html>` | 告訴瀏覽器使用 HTML5 標準解析網頁 |
| `<html lang="zh-Hant">` | 整份 HTML 的根元素，並指定內容為繁體中文 |
| `<head>` | 放置網頁設定，通常不直接顯示於頁面 |
| `<meta charset="UTF-8">` | 使用 UTF-8 編碼，避免中文亂碼 |
| `<meta name="viewport" ...>` | 讓網頁在手機上依裝置寬度正確顯示 |
| `<title>` | 瀏覽器分頁上顯示的標題 |
| `<body>` | 放置使用者實際看得到的網頁內容 |

### body 載入事件

```html
<body onload="alert('Hello, world!');">
</body>
```

- `onload`：頁面內容載入完成後執行。
- `alert()`：JavaScript 的提示視窗函式。
- 實務上通常建議把 JavaScript 寫在獨立的 `<script>` 中，讓結構與程式分離。

## 二、標題、段落與換行

### 1. 標題 `<h1>`～`<h6>`

```html
<h1>標題 1</h1>
<h2>標題 2</h2>
<h3>標題 3</h3>
<h4>標題 4</h4>
<h5>標題 5</h5>
<h6>標題 6</h6>
```

- `<h1>` 是最高層級標題，`<h6>` 是最低層級標題。
- 標題數字代表內容層級，不只是字體大小。
- 一般頁面應有清楚的標題階層，不要只為了外觀而跳級。

### 2. 段落 `<p>` 與換行 `<br>`

```html
<p>
  天命之謂性，率性之謂道，修道之謂教。<br>
  道也者，不可須臾離也；可離，非道也。
</p>
```

- `<p>` 用來表示一個段落，瀏覽器預設會在上下加入外距 `margin`。
- `<br>` 只負責在同一段內容中強制換行，不需要結束標籤。
- 不建議連續使用很多 `<br>` 製造版面間距；間距應交給 CSS 的 `margin` 或 `padding`。

```css
p {
  text-indent: 2em; /* 首行縮排兩個中文字寬度 */
}
```

`em` 是相對於目前元素字體大小的單位，因此 `2em` 約等於兩個文字寬度。

### 3. 水平分隔線 `<hr>`

```html
<p>春曉</p>
<hr>
<p>春眠不覺曉，處處聞啼鳥……</p>
```

`<hr>` 表示內容主題的轉換或分隔，不只是畫一條線。可以使用 CSS 修改外觀：

```html
<hr style="height: 5px; background-color: blue; border: 5px solid darkred;">
```

課堂範例也使用了：

```css
float: left;  /* 讓較短的水平線靠左 */
clear: both;  /* 清除前方浮動，避免後面的內容繞上去 */
```

現代版面通常優先使用 Flexbox 或 Grid；`float` 主要適合文字環繞圖片等用途。

### 4. 預格式化文字 `<pre>`

```html
<pre>
void main()
{
  printf("Hello, world!\n");
}
</pre>
```

`<pre>` 會保留原始碼中的空白、縮排和換行，適合顯示程式碼或格式化文字。若要表達「程式碼」，可再搭配 `<code>`：

```html
<pre><code>console.log("Hello, world!");</code></pre>
```

### 5. HTML 註解

```html
<!-- 這是 HTML 註解，不會顯示在網頁上 -->
```

註解適合說明程式用途或暫時標記內容，但不要在註解中放密碼、金鑰或其他敏感資料，因為使用者仍可查看網頁原始碼。

## 三、特殊字元與行內文字

```html
<h1>Hello <i>world</i></h1>
<p>Hello&nbsp;&nbsp;HTML5</p>
<p>HTML5 の世界へようこそ&lt;P&gt;</p>
<a href="https://apple.com/tw">&quot;Apple 官網&quot;&copy;</a>
```

| 實體字元 | 顯示結果 | 用途 |
|---|---|---|
| `&nbsp;` | 不換行空白 | 插入不會被合併的空白 |
| `&lt;` | `<` | 顯示小於符號或 HTML 左角括號 |
| `&gt;` | `>` | 顯示大於符號或 HTML 右角括號 |
| `&quot;` | `"` | 顯示雙引號 |
| `&copy;` | © | 顯示著作權符號 |

`<i>` 會以斜體呈現文字；若內容是需要強調的語意，通常使用 `<em>` 更合適。

屬性必須寫在開始標籤裡：

```html
<!-- 正確 -->
<h1 title="hello, HTML5">Hello, HTML5</h1>

<!-- 原範例把 title 當成文字，因此不會成為提示屬性 -->
<h1>title="hello,HTML5" Hello, HTML5</h1>
```

## 四、區塊元素與行內容器

### 1. `<div>` 區塊容器

```html
<div id="navigation">
  <ul>
    <li><a href="products.html">產品型錄</a></li>
    <li><a href="stores.html">銷售門市</a></li>
  </ul>
</div>
```

- `<div>` 是沒有特定語意的通用區塊容器。
- 預設為區塊元素，通常會從新的一行開始並占滿可用寬度。
- 高度預設為 `auto`，會依內容撐開。
- `<div>` 本身通常沒有預設上下外距；但裡面的 `<ul>`、`<p>` 等可能有預設外距。

### 2. `<span>` 行內容器

```html
<span style="color: blue;">這段文字是藍色</span>
```

- `<span>` 是沒有特定語意的通用行內容器。
- 不會自動換行，寬高預設由內容決定，而不是 `100%`。
- 適合替句子中的部分文字套用樣式。

| 比較 | `<div>` | `<span>` |
|---|---|---|
| 預設顯示方式 | 區塊 `block` | 行內 `inline` |
| 是否通常換行 | 是 | 否 |
| 預設寬度 | 填滿可用寬度 | 依內容決定 |
| 常見用途 | 分組整個區域 | 標記部分文字 |

## 五、引用內容 `<blockquote>`

```html
<blockquote cite="https://www.w3.org/">
  這是一段來自其他來源的長篇引用內容。
</blockquote>
```

- `<blockquote>` 表示區塊形式的引用，瀏覽器通常會加上左右縮排。
- `cite` 屬性用來記錄引用來源網址，但瀏覽器通常不會直接把網址顯示出來。
- 一般 `<div cite="...">` 沒有相同的引用語意；即使外觀可用 CSS 模仿，語意仍不同。

```css
blockquote {
  margin: 16px 40px;
}
```

注意：課堂範例的 CSS 使用 `#p`、`#blockquote`，這是 ID 選擇器，只會選到 `id="p"` 與 `id="blockquote"` 的元素，不是直接選擇 `<p>` 或 `<blockquote>` 標籤。

## 六、HTML5 語意化結構

語意化標籤能讓瀏覽器、搜尋引擎、輔助工具及開發者更容易了解內容的角色。

| 標籤 | 用途 |
|---|---|
| `<header>` | 頁面或某個區塊的頁首、標題與介紹 |
| `<nav>` | 主要導覽連結 |
| `<main>` | 頁面最主要且通常唯一的內容 |
| `<article>` | 可獨立閱讀或散布的內容，如文章、新聞、貼文 |
| `<section>` | 依主題劃分的章節，通常帶有標題 |
| `<aside>` | 與主要內容相關但非核心的補充內容 |
| `<footer>` | 頁尾、版權、作者或相關連結 |
| `<figure>` | 圖片、圖表或程式碼等自成一體的內容 |
| `<figcaption>` | `<figure>` 的標題或說明文字 |

### 1. `<header>` 與 `<footer>`

```html
<header>
  <h1>手機王</h1>
  <p>找手機、修手機、賣手機，手機專家就在這裡！</p>
</header>

<footer>
  <p>&copy; 2025 快樂通訊公司</p>
  <p><a href="#">Back to top</a></p>
</footer>
```

`href="#"` 會跳到目前頁面頂端，但更清楚的做法是替頁首設定 ID，例如 `href="#top"` 搭配 `<body id="top">`。

### 2. `<nav>` 導覽列

```html
<nav aria-label="主要導覽">
  <ul>
    <li><a href="products.html">產品型錄</a></li>
    <li><a href="stores.html">銷售門市</a></li>
    <li><a href="about.html">關於我們</a></li>
  </ul>
</nav>
```

`<nav>` 適合包住網站的主要導覽。`<li>` 雖然在 HTML 中某些情況可省略結束標籤，但初學與團隊開發時建議完整寫出 `</li>`。

### 3. `<main>`、`<article>` 與 `<section>`

```html
<main>
  <article>
    <h1>唐詩欣賞</h1>

    <section>
      <h2>送別</h2>
      <p>山中相送罷，日暮掩柴扉……</p>
    </section>

    <section>
      <h2>鹿柴</h2>
      <p>空山不見人，但聞人語響……</p>
    </section>
  </article>
</main>
```

- `<main>`：整頁的核心內容，一頁通常只放一個可見的 `<main>`。
- `<article>`：抽離頁面後仍能獨立成立的完整內容。
- `<section>`：同一篇內容中依主題切分的章節，通常應附標題。

### 4. `<aside>` 側欄

```html
<aside>
  <section>
    <h2>您可能會有興趣的文章</h2>
    <ul>
      <li><a href="article1.html">文章 1</a></li>
      <li><a href="article2.html">文章 2</a></li>
    </ul>
  </section>
</aside>
```

`<aside>` 常用於相關文章、廣告、作者簡介或補充資訊。若文字實際上是區塊標題，使用 `<h2>` 比 `<p>` 更能表達結構。

### 5. `<figure>`、圖片與圖說

```html
<figure>
  <img src="flower.jpg" width="400" alt="粉紅色百合花">
  <figcaption>圖片來源：攝影師 Somben Chea／Pexels</figcaption>
</figure>
```

- `src`：圖片路徑；此例表示圖片與 HTML 位於同一資料夾。
- `width`：顯示寬度，未指定單位時以 CSS 像素計算。
- `alt`：圖片替代文字；圖片載入失敗或使用螢幕閱讀器時很重要。
- `<figcaption>` 必須放在 `<figure>` 內，且應位於內容的第一個或最後一個子元素。

建議讓圖片在小螢幕內自動縮小：

```css
img {
  max-width: 100%;
  height: auto;
}
```

## 七、CSS 樣式基礎

### 1. 內部樣式表

```html
<style>
  body {
    background-color: hotpink;
  }

  p {
    color: white;
    background-color: brown;
  }
</style>
```

CSS 基本格式：

```css
選擇器 {
  屬性: 值;
}
```

課堂 `style.html` 中的 `color: whitem;` 拼字錯誤，瀏覽器會忽略這一行；應改為 `color: white;`。

### 2. 常見選擇器

```css
p { color: blue; }          /* 標籤選擇器：所有 p */
#navigation { color: red; } /* ID 選擇器：id="navigation" */
.notice { color: orange; }  /* Class 選擇器：class="notice" */
p, h1 { color: aqua; }      /* 群組選擇器：同時選 p 與 h1 */
* { margin: 0; padding: 0; }/* 通用選擇器：所有元素 */
```

- `id` 在同一頁中應保持唯一。
- 多個元素要共用樣式時，優先使用 `class`。
- `* { margin: 0; padding: 0; }` 會清除所有元素的預設間距，之後要自行補回適當間距。

### 3. 外距、內距與外距重疊

- `margin`：元素邊框外側的距離。
- `padding`：內容與邊框之間的距離。
- 相鄰區塊的垂直 `margin` 可能發生重疊，通常以較大的值呈現，而不是直接相加。

### 4. 文字裝飾

```css
.title {
  color: salmon;
  text-decoration-line: underline;
  text-decoration-color: red;
  text-decoration-thickness: 3px;
  text-underline-offset: 5px;
}
```

這些屬性分別設定文字顏色、底線、底線顏色、粗細與底線距離。

## 八、滑鼠事件與 JavaScript

```html
<img
  src="b.svg"
  alt="笑臉"
  width="32"
  height="32"
  onmouseover="bigImg(this)"
  onmouseout="normalImg(this)"
>

<script>
  function bigImg(image) {
    // 滑鼠移入時放大圖片
    image.style.width = "64px";
    image.style.height = "64px";
  }

  function normalImg(image) {
    // 滑鼠移出時恢復圖片大小
    image.style.width = "32px";
    image.style.height = "32px";
  }
</script>
```

| 語法 | 說明 |
|---|---|
| `onmouseover` | 滑鼠指標進入元素時觸發 |
| `onmouseout` | 滑鼠指標離開元素時觸發 |
| `this` | 代表目前觸發事件的元素，也就是該圖片 |
| `element.style.width` | 用 JavaScript 修改元素的行內 CSS |

`border="0"` 是較舊的 HTML 寫法，現代寫法使用 CSS：`style="border: 0;"`。

若只是滑鼠移入放大圖片，其實不一定需要 JavaScript，也可以使用 CSS：

```css
img.icon {
  width: 32px;
  height: 32px;
  transition: transform 0.2s;
}

img.icon:hover {
  transform: scale(2);
}
```

## 九、完整語意化網頁版面

```html
<!DOCTYPE html>
<html lang="zh-Hant">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>手機王</title>
    <style>
      * {
        box-sizing: border-box;
      }

      body {
        margin: 0;
        background-color: lightgray;
      }

      header {
        padding: 16px;
        background-color: gray;
      }

      nav {
        padding: 10px;
        color: white;
        background-color: black;
      }

      nav ul {
        display: flex;
        justify-content: center;
        gap: 20px;
        margin: 0;
        padding: 0;
        list-style: none;
      }

      nav a {
        color: white;
      }

      .content-layout {
        display: flex;
        min-height: 60vh;
      }

      main {
        width: 70%;
        padding: 16px;
        background-color: skyblue;
      }

      aside {
        width: 30%;
        padding: 16px;
        background-color: pink;
      }

      footer {
        padding: 16px;
        background-color: #eaeaea;
      }

      @media (max-width: 700px) {
        .content-layout {
          flex-direction: column;
        }

        main,
        aside {
          width: 100%;
        }
      }
    </style>
  </head>
  <body id="top">
    <header>
      <h1>手機王</h1>
      <p>找手機、修手機、賣手機，手機專家就在這裡！</p>

      <nav aria-label="主要導覽">
        <ul>
          <li><a href="products.html">產品型錄</a></li>
          <li><a href="stores.html">銷售門市</a></li>
          <li><a href="about.html">關於我們</a></li>
        </ul>
      </nav>
    </header>

    <div class="content-layout">
      <main>
        <article>
          <h2>翠玉白菜</h2>
          <p>《翠玉白菜》是故宮博物院珍藏的玉器雕刻……</p>
        </article>

        <article>
          <h2>肉形石</h2>
          <p>《肉形石》是故宮博物院珍藏的國寶之一……</p>
        </article>
      </main>

      <aside>
        <section>
          <h2>您可能會有興趣的文章</h2>
          <ul>
            <li><a href="article1.html">文章 1</a></li>
            <li><a href="article2.html">文章 2</a></li>
          </ul>
        </section>
      </aside>
    </div>

    <footer>
      <p>&copy; 2025 快樂通訊公司</p>
      <p><a href="#top">Back to top</a></p>
    </footer>
  </body>
</html>
```

### 與課堂 `main.html` 的差異

1. 使用 Flexbox 建立 70%／30% 欄位，取代 `float`，不用另外 `clear: both`。
2. 不把 `main`、`aside` 設成 `height: 100%`，避免內容溢出或高度難以控制。
3. 加入 `box-sizing: border-box`，讓寬度包含 `padding`，較容易計算。
4. 加入媒體查詢，小螢幕時主內容與側欄會改為上下排列。
5. 導覽連結加上文字顏色，避免黑色背景上看不清楚。

## 十一、常見錯誤與考試重點

1. 忘記寫 `<!DOCTYPE html>`，可能讓瀏覽器進入非標準模式。
2. 中文網頁忘記設定 `<meta charset="UTF-8">`，可能出現亂碼。
3. 把標籤屬性寫成畫面文字；屬性應放在開始標籤內。
4. 使用不存在的 CSS 值，例如 `whitem`；錯誤的宣告會被瀏覽器忽略。
5. 混淆 `<div>` 與 `<span>`：前者預設為區塊，後者預設為行內。
6. 用大量 `<br>` 排版；應改用 CSS 控制間距。
7. 只看語意標籤的外觀：`article`、`section`、`aside` 的重點是內容角色，不是預設樣式。
8. 圖片省略 `alt`，會影響無障礙與圖片失效時的資訊呈現。
9. 一頁放置多個主要 `<main>`，會讓文件結構不清楚。
10. 所有區塊都用 `<div>`；有明確用途時應優先使用適合的語意化標籤。

## 十二、快速複習

- 網頁設定放在 `<head>`，畫面內容放在 `<body>`。
- `<h1>`～`<h6>` 表示標題層級；`<p>` 表示段落。
- `<div>` 是通用區塊；`<span>` 是通用行內容器。
- `<header>`、`nav`、`main`、`article`、`section`、`aside`、`footer` 用來建立清楚的語意結構。
- `<figure>` 搭配 `<figcaption>` 說明圖片或圖表。
- CSS 控制外觀，JavaScript 控制互動。
- 使用正確語意、完整結束標籤、圖片 `alt` 與響應式設定，可以讓網頁更容易維護。
