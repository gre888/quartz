# 9/14 SQL 上課重點整理

## 一、子查詢 Subquery ⭐⭐⭐

### 1. 基本觀念

**子查詢 = SQL 裡面再放一個 SQL。**

通常執行順序是：

> **先執行括號裡面的子查詢 → 再執行外面的主查詢**

基本格式：

```
SELECT 欄位
FROM 資料表
WHERE 欄位 運算子 (
    SELECT 欄位
    FROM 資料表
    WHERE 條件
);
```

例如：找出人口比美國多的國家。

```
SELECT CODE, POPULATION
FROM WORLD.COUNTRY
WHERE POPULATION >
(
    SELECT POPULATION
    FROM WORLD.COUNTRY
    WHERE CODE = 'USA'
);
```

思考方式：

```
① 先找 USA 人口
        ↓
② 得到一個人口數
        ↓
③ 找 POPULATION > 美國人口 的國家
```

---

# 二、`=` 與 `IN` 的差別 ⭐⭐⭐

這是非常重要的考點。

### 子查詢只有「一筆結果」

可以使用：

```
=
>
<
>=
<=
<>
```

例如：

```
SELECT NAME, GNP
FROM WORLD.COUNTRY
WHERE GNP =
(
    SELECT MAX(GNP)
    FROM WORLD.COUNTRY
);
```

意思是：

> 找出 GNP 等於「全世界最大 GNP」的國家。

---

### 子查詢可能有「很多筆結果」

使用：

```
IN
```

例如：

```
SELECT NAME
FROM WORLD.COUNTRY
WHERE CODE IN
(
    SELECT COUNTRYCODE
    FROM WORLD.CITY
    WHERE POPULATION > 9000000
);
```

意思：

> 找出「擁有人口超過 900 萬城市」的國家。

### 考試記法

|子查詢結果|常用寫法|
|---|---|
|一個值|`=`、`>`、`<`|
|多個值|`IN`、`NOT IN`|

---

# 三、`IN` 與 `NOT IN` ⭐⭐⭐

## IN

符合其中任何一個即可。

```
SELECT NAME
FROM WORLD.COUNTRY
WHERE CODE IN ('BRA', 'IDN', 'CHN');
```

可以理解成：

```
CODE = BRA
OR
CODE = IDN
OR
CODE = CHN
```

---

## NOT IN

排除子查詢找到的資料。

```
SELECT NAME
FROM WORLD.COUNTRY
WHERE CODE NOT IN
(
    SELECT COUNTRYCODE
    FROM WORLD.CITY
    WHERE POPULATION > 9000000
);
```

意思：

> 找出沒有「人口超過 900 萬城市」的國家。

---

# 四、ALL、ANY、SOME ⭐⭐⭐

這部分很容易出選擇題。

假設子查詢得到：

```
2
3
```

## ALL = 全部都要成立

```
N > ALL (2, 3)
```

等於：

```
N > 2 AND N > 3
```

所以其實就是：

```
N > 3
```

### 常見快速判斷

```
> ALL → 大於最大值
< ALL → 小於最小值
```

例如：

```
SELECT *
FROM TEST.OUTERTABLE
WHERE N > ALL
(
    SELECT N
    FROM TEST.INNERTABLE
);
```

---

# 五、ANY / SOME ⭐⭐⭐

`ANY` 與 `SOME` 基本上是相同概念。

只要其中一個條件成立即可。

假設：

```
子查詢 → 2, 3
```

那麼：

```
N > ANY (2, 3)
```

相當於：

```
N > 2 OR N > 3
```

因此只需要：

```
N > 2
```

### 超級重要口訣

|寫法|意思|
|---|---|
|`> ALL`|大於最大值|
|`< ALL`|小於最小值|
|`> ANY`|大於最小值|
|`< ANY`|小於最大值|
|`ANY`|任一成立|
|`SOME`|與 ANY 類似|
|`ALL`|全部成立|

### ALL 看 AND；ANY 看 OR

這個最好記：

```
ALL  → AND
ANY  → OR
SOME → OR
```

---

# 六、`<> ALL` 的特殊用法

上課範例：

公司正式員工：

```
A B C D E F G
```

工讀生：

```
C D
```

要找「不是工讀生的正式員工」。

```
SELECT *
FROM TEST.EMP
WHERE N <> ALL
(
    SELECT N
    FROM TEST.PARTIME
);
```

概念：

```
N <> C
AND
N <> D
```

結果：

```
A B E F G
```

也就是「跟所有工讀生都不相同」。

---

# 七、多欄位子查詢 ⭐⭐⭐

不一定只能比較一個欄位，也可以一次比較兩個以上欄位。

例如：

```
SELECT *
FROM MYLAB.PET
WHERE (SPECIES, GENDER) =
(
    SELECT SPECIES, GENDER
    FROM MYLAB.PET
    WHERE NAME = 'FANG'
);
```

意思：

> 找出「物種 + 性別」都跟 FANG 一樣的寵物。

注意左右欄位要對應：

```
SPECIES ↔ SPECIES
GENDER  ↔ GENDER
```

---

# 八、找每個洲 GNP 最大的國家 ⭐⭐⭐

這題很值得記。

先找每洲最大 GNP：

```
SELECT CONTINENT, MAX(GNP)
FROM WORLD.COUNTRY
GROUP BY CONTINENT;
```

結果概念：

```
Asia          最大GNP
Europe        最大GNP
North America 最大GNP
...
```

再找是哪個國家：

```
SELECT CONTINENT, NAME, GNP
FROM WORLD.COUNTRY
WHERE (CONTINENT, GNP) IN
(
    SELECT CONTINENT, MAX(GNP)
    FROM WORLD.COUNTRY
    GROUP BY CONTINENT
);
```

這裡結合了兩個重要觀念：

```
GROUP BY
+
多欄位子查詢
```

---

# 九、子查詢可以放在 SELECT 裡

子查詢不一定只能出現在 `WHERE`。

例如：

```
SELECT CONCAT(
    'JAPAN GNP= ',
    (SELECT GNP
     FROM WORLD.COUNTRY
     WHERE NAME = 'JAPAN')
);
```

先查 Japan GNP，再與文字串接。

---

# 十、子查詢可以放在 FROM 裡 ⭐⭐

```
SELECT NAME, GNP
FROM
(
    SELECT *
    FROM WORLD.COUNTRY
    WHERE CONTINENT = 'ASIA'
) AS ASIACOUNTRY;
```

括號裡先產生一個「暫時的查詢結果」。

外面再：

```
SELECT NAME, GNP
```

### 注意

放在 `FROM` 裡面的子查詢通常需要別名：

```
AS ASIACOUNTRY
```

# 十一、子查詢搭配 UPDATE ⭐⭐⭐

上課例子：SALES 部門員工加薪 50。

```
UPDATE CMDEV.EMP
SET SALARY = SALARY + 50
WHERE DEPNO IN
(
    SELECT DEPTNO
    FROM CMDEV.DEPT
    WHERE DNAME = 'SALES'
);
```

執行概念：

```
先找 SALES 的 DEPTNO
        ↓
找到該部門員工
        ↓
SALARY + 50
```

---

# 十二、子查詢搭配 DELETE

例如：

```
DELETE FROM CMDEV.EMP
WHERE DEPTNO IN
(
    SELECT DEPTNO
    FROM CMDEV.DEPT
    WHERE DNAME = 'SALES'
);
```

概念：

> 先找 SALES 部門編號，再刪除該部門員工。

⚠️ `UPDATE`、`DELETE` 考試時要特別注意 `WHERE`，沒有 `WHERE` 可能影響整張表。

# 十三、關聯子查詢 Correlated Subquery ⭐⭐⭐

這是這堂課比較進階的重點。

題目：

> 找出「比自己主管更早進公司」的員工。

```
SELECT EMPNO, ENAME, MANAGER, HIREDATE
FROM CMDEV.EMP E
WHERE HIREDATE <
(
    SELECT HIREDATE
    FROM CMDEV.EMP
    WHERE EMPNO = E.MANAGER
);
```

關鍵在：

```
E.MANAGER
```

裡面的子查詢會使用到外層查詢目前這位員工的資料。

概念：

```
員工 A → 找 A 的主管 → 比日期
員工 B → 找 B 的主管 → 比日期
員工 C → 找 C 的主管 → 比日期
...
```

所以和一般子查詢不同。

### 一般子查詢 vs 關聯子查詢

|類型|特性|
|---|---|
|一般子查詢|子查詢可以自己獨立執行|
|關聯子查詢|子查詢會引用外層資料|
|關聯子查詢|通常針對外層每筆資料進行比較|

# 十四、CREATE TABLE + 子查詢

## LIKE：複製資料表結構

```
CREATE TABLE WORLD.MYCOUNTRY
LIKE WORLD.COUNTRY;
```

主要是建立相同結構。

再把資料放進去：

```
INSERT INTO WORLD.MYCOUNTRY
SELECT *
FROM WORLD.COUNTRY
WHERE CONTINENT = 'ASIA';
```

概念：

```
CREATE TABLE → 建表
INSERT SELECT → 把查詢結果加入新表
```

---

# 十五、REPLACE INTO

上課範例：

```
REPLACE INTO WORLD.MYCOUNTRY
SELECT *
FROM WORLD.COUNTRY
WHERE CONTINENT = 'AFRICA';
```

`REPLACE` 跟 `INSERT` 不完全一樣。

如果遇到 `PRIMARY KEY` / `UNIQUE` 衝突，MySQL 的 `REPLACE` 會以替換方式處理資料。

考試要知道：

```
INSERT  → 新增
UPDATE  → 修改
DELETE  → 刪除
REPLACE → 新增或替換
```

# 十六、ENUM ⭐⭐⭐

第二份 SQL 的重要內容。

`ENUM` = **列舉**

意思是：

> 一個欄位只能從「預先規定的選項」選一個。

概念例如：

```
size ENUM('S','M','L')
```

只能選：

```
S
M
L
```

例如：

```
SELECT *
FROM ENUMTABLE
WHERE ENUMSIZE = 'M';
```

---

## ENUM 有索引位置

假設：

```
ENUM('S','M','L')
```

概念上：

```
S → 1
M → 2
L → 3
```

所以課堂才會出現：

```
WHERE ENUMSIZE = 3
```

這類題目容易考「ENUM 字串值與內部索引」。

---

# 十七、SET ⭐⭐⭐

`SET` = **集合**

跟 ENUM 最大差異：

```
ENUM → 只能選一個
SET  → 可以選多個
```

例如工作日：

```
SET('MON','TUE','WED','THU','FRI','SAT','SUN')
```

可以：

```
'MON'
```

也可以：

```
'MON,TUE,WED'
```

---

# 十八、SET 的數字概念 ⭐⭐

SET 內部可以用 bit 位元方式表示。

概念：

```
第1個 → 1
第2個 → 2
第3個 → 4
第4個 → 8
第5個 → 16
第6個 → 32
第7個 → 64
```

所以：

```
INSERT INTO SETTABLE VALUES (21);
```

因為：

```
21 = 1 + 4 + 16
```

代表選中了對應的第：

```
1、3、5
```

個 SET 成員。

這跟 Python 的「set 集合」不是同一個東西；這裡是 **MySQL SET 欄位型態**。

---

# 十九、ENUM vs SET 必考比較

|比較|ENUM|SET|
|---|---|---|
|中文|列舉|集合|
|可選數量|一個|多個|
|例子|性別、尺寸、等級|興趣、工作日|
|`'M'`|可以|視定義|
|`'MON,WED'`|❌|✅|
|內部數字|索引|位元組合|

### 一句話記憶

> **ENUM 單選，SET 複選。**

```
子查詢 → 先裡後外

單一結果 → = > < >= <=
多筆結果 → IN / NOT IN

ALL  → 全部成立 → AND
ANY  → 任一成立 → OR
SOME → 類似 ANY

> ALL → 大於最大值
< ALL → 小於最小值
> ANY → 大於最小值
< ANY → 小於最大值

ENUM → 單選
SET  → 複選

一般子查詢 → 裡面可以獨立查
關聯子查詢 → 裡面會引用外層資料
```
