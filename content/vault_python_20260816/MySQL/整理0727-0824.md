# MySQL 考試重點整理

> 依照本次上傳的 SQL 上課檔案整理。\
> 建議考前優先熟悉：**SELECT 查詢、WHERE 條件、函數、GROUP
> BY/HAVING、CREATE/ALTER
> TABLE、主鍵與索引、INSERT/UPDATE/DELETE、交易控制**。

------------------------------------------------------------------------

## 1. SQL 指令分類

  類型   用途                     常見指令
  ------ ------------------------ -------------------------------------------
  DDL    定義資料庫與資料表結構   `CREATE`、`ALTER`、`DROP`、`TRUNCATE`
  DML    新增、修改、刪除資料     `INSERT`、`UPDATE`、`DELETE`、`REPLACE`
  DQL    查詢資料                 `SELECT`
  TCL    交易控制                 `START TRANSACTION`、`COMMIT`、`ROLLBACK`

### 必背差異

-   `DELETE`：刪除資料列，可以搭配 `WHERE`。
-   `TRUNCATE`：快速清空整張表，不使用 `WHERE`。
-   `DROP TABLE`：連資料表結構一起刪除。
-   `UPDATE`：修改既有資料。
-   `INSERT`：新增資料。

# 3. SELECT 基本查詢【超重要】

基本格式：

``` sql
SELECT 欄位
FROM 資料表
WHERE 條件
ORDER BY 欄位;
```

例如：

``` sql
SELECT name, population
FROM world.city
WHERE population > 5000000;
```

## 查詢全部欄位

``` sql
SELECT * FROM world.country;
```

## 欄位別名 AS

``` sql
SELECT
    id AS '編號',
    name AS '姓名'
FROM world.city;
```

`AS` 可以省略：

``` sql
SELECT name '姓名'
FROM world.city;
```

## 計算欄位

``` sql
SELECT name, population * 2 AS '2倍人口'
FROM world.city;
```

## IN

多個可能值：

``` sql
SELECT *
FROM world.country
WHERE continent IN ('Asia', 'Europe', 'Africa');
```

相當於：

``` sql
WHERE continent = 'Asia'
   OR continent = 'Europe'
   OR continent = 'Africa'
```

### 考試記憶

> 同一欄位要比對多個固定值 → `IN`

# 7. NULL【非常容易考】

錯誤：

``` sql
NULL = NULL
```

結果不是一般的 True。

正確判斷：

``` sql
IS NULL
IS NOT NULL
```

例如：

``` sql
WHERE comm IS NULL
```

MySQL 也有 NULL-safe equality：

``` sql
NULL <=> NULL
```

結果為真。

## NULL 參與運算

``` sql
SELECT NULL + 3;
```

結果：

``` text
NULL
```

因此：

``` sql
salary + comm
```

如果 `comm` 是 NULL，結果也是 NULL。

### 解法：IFNULL()

``` sql
SELECT
    salary,
    comm,
    salary + IFNULL(comm, 0) AS total
FROM cmdev.emp;
```

### 必背

``` sql
IFNULL(欄位, 替代值)
```

# 13. CASE WHEN【超重要】

## 多條件 CASE

``` sql
SELECT
    ename,
    salary,
    CASE
        WHEN salary >= 3000 THEN 'A級'
        WHEN salary >= 1000 THEN 'B級'
        ELSE 'C級'
    END AS grade
FROM cmdev.emp;
```

判斷由上往下。

因此第二個條件不必再寫：

``` sql
salary <= 2999
```

因為 \>=3000 已經被第一個 WHEN 處理。

------------------------------------------------------------------------

## CASE 欄位 WHEN

``` sql
CASE continent
    WHEN 'Asia' THEN 'AS'
    WHEN 'Europe' THEN 'EU'
    WHEN 'Africa' THEN 'AF'
    ELSE 'NONE'
END
```

## COUNT(\*) vs COUNT(欄位)【常考】

``` sql
COUNT(*)
```

計算所有資料列。

``` sql
COUNT(comm)
```

> `COUNT(*)` → 所有列\
> `COUNT(column)` → 忽略 NULL

# 15. GROUP BY【超重要】

依職務計算平均薪資：

``` sql
SELECT job, AVG(salary)
FROM cmdev.emp
GROUP BY job;
```

依洲別計算人口：

``` sql
SELECT continent, SUM(population)
FROM world.country
GROUP BY continent;
```

### 核心觀念

> `GROUP BY` 是「先分類，再計算」。

例如：

``` sql
GROUP BY job
```

就是把相同 `job` 放成一組。

# 16. WHERE 與 HAVING 差異【必考】

## WHERE

先篩選「原始資料」。

``` sql
SELECT region, SUM(population)
FROM world.country
WHERE continent = 'Asia'
GROUP BY region;
```

## HAVING

篩選「群組計算後的結果」。

``` sql
SELECT region, SUM(population)
FROM world.country
GROUP BY region
HAVING SUM(population) > 1000000;
```

### 必背

  指令       篩選什麼
  ---------- -------------------
  `WHERE`    分組前的資料列
  `HAVING`   GROUP BY 後的群組

錯誤觀念：

``` sql
WHERE SUM(population) > 1000000
```

聚合結果通常應使用 `HAVING`。

# 22. PRIMARY KEY 主鍵【超重要】

``` sql
id INT PRIMARY KEY
```

主鍵特性：

1.  不可重複
2.  不可為 NULL
3.  一張表只能有一個 Primary Key
4.  主鍵可以包含多個欄位

## 複合主鍵

``` sql
PRIMARY KEY(deptno, dname)
```

意思：

> `deptno + dname` 的組合不可重複。

不是代表兩個獨立主鍵。

# 29. CREATE TABLE AS 與 LIKE 差異

只複製查詢得到的結構/資料：

``` sql
CREATE TABLE cityofworld AS
SELECT *
FROM world.city
WHERE 1 = 0;
```

`WHERE 1=0` 永遠不成立，因此只建立欄位結構、沒有資料。

若要複製原資料表結構與索引等資訊，課堂範例使用：

``` sql
CREATE TABLE cityofnewworld
LIKE world.city;
```

### 考試記憶

> `AS SELECT` → 偏向複製查詢結果\
> `LIKE` → 偏向複製原表結構

# 35. ON DUPLICATE KEY UPDATE【很重要】

``` sql
INSERT INTO cmdev.travel
VALUES (7369, 'chicago', 1)
ON DUPLICATE KEY UPDATE
counter = counter + 1;
```

意思：

-   主鍵/唯一鍵不存在 → INSERT
-   已存在 → UPDATE

### 記憶

> 「有就更新，沒有就新增」

# 36. REPLACE INTO

``` sql
REPLACE INTO cmdev.travel
VALUES (7369, 'boston', 10);
```

也可以：

``` sql
REPLACE INTO cmdev.travel
SET empno = 7369,
    location = 'boston',
    counter = 1;
```

### 與 ON DUPLICATE KEY UPDATE 的觀念差異

`REPLACE` 遇到重複鍵時偏向「替換原資料」；\
`ON DUPLICATE KEY UPDATE` 則明確指定要更新哪些欄位。

考試若要做：

``` sql
counter = counter + 1
```

通常使用：

``` sql
ON DUPLICATE KEY UPDATE
```

最直觀。

# 40. Transaction 交易【超重要】

開始交易：

``` sql
START TRANSACTION;
```

永久確認：

``` sql
COMMIT;
```

取消尚未提交的交易：

``` sql
ROLLBACK;
```

例如：

``` sql
START TRANSACTION;

UPDATE cmdev.travel
SET counter = 100
WHERE empno = 7521
  AND location = 'DALLAS';

COMMIT;
```

如果發現修改錯誤：

``` sql
START TRANSACTION;

DELETE FROM cmdev.travel
WHERE empno = 7521
  AND location = 'DALLAS';

ROLLBACK;
```

### 必背

``` text
START TRANSACTION
       ↓
   UPDATE/DELETE
       ↓
檢查結果
   ↙       ↘
COMMIT   ROLLBACK
確認       復原
```

### 課堂範例的重要陷阱

`TRUNCATE` 屬於 DDL 類操作，在 MySQL 中通常會造成隱含提交，**不能期待用
ROLLBACK 把 TRUNCATE 復原**。

# 41. DISTINCT 去除重複

``` sql
SELECT DISTINCT job
FROM cmdev.emp;
```

只顯示不同的職務。

也可搭配：

``` sql
GROUP_CONCAT(DISTINCT job)
```

# 42. SQL_MODE / ONLY_FULL_GROUP_BY

課堂範例：

``` sql
SET SQL_MODE = 'ONLY_FULL_GROUP_BY';
```

開啟後，`GROUP BY` 查詢會要求 SELECT 中非聚合欄位與分組規則相容。

例如這種寫法可能有問題：

``` sql
SELECT region, SUM(population)
FROM world.country
GROUP BY continent;
```

因為：

``` text
SELECT region
```

但卻：

``` text
GROUP BY continent
```

考試應優先寫成邏輯一致的形式：

``` sql
SELECT region, SUM(population)
FROM world.country
GROUP BY region;
```

# 43. 考試常見錯誤整理

## 錯誤 1：NULL 用 = 判斷

❌

``` sql
WHERE comm = NULL
```

✅

``` sql
WHERE comm IS NULL
```

------------------------------------------------------------------------

## 錯誤 2：聚合條件放 WHERE

❌

``` sql
WHERE SUM(population) > 1000000
```

✅

``` sql
HAVING SUM(population) > 1000000
```

------------------------------------------------------------------------

## 錯誤 3：UPDATE 忘記 WHERE

``` sql
UPDATE emp
SET salary = 0;
```

會修改全部資料。

------------------------------------------------------------------------

## 錯誤 4：DELETE 忘記 WHERE

``` sql
DELETE FROM emp;
```

會刪除全部資料。

------------------------------------------------------------------------

## 錯誤 5：CREATE TABLE 最後一個欄位多逗號

❌

``` sql
CREATE TABLE product (
    id INT,
    name VARCHAR(20),
);
```

最後一欄後面不能多逗號。

------------------------------------------------------------------------

## 錯誤 6：AUTO_INCREMENT 沒有適當索引

最常見安全寫法：

``` sql
id INT AUTO_INCREMENT PRIMARY KEY
```

------------------------------------------------------------------------

## 錯誤 7：把字串當欄位名稱

❌

``` sql
CONCAT_WS('$$$', 'code', 'name')
```

這會串接文字 `code`、`name`。

✅

``` sql
CONCAT_WS('$$$', code, name)
```

這才是串接欄位內容。

------------------------------------------------------------------------

## 錯誤 8：CASE 拼字錯誤

資料庫若是：

``` text
PRESIDENT
```

條件也必須正確對應：

``` sql
WHEN 'PRESIDENT' THEN ...
```

不要寫成：

``` text
prisident
```

# 44. 綜合題型 1：職務薪資統計

題目：

> 依職務分組，顯示薪資合計、平均、最大、最小。

答案：

``` sql
SELECT
    job,
    SUM(salary) AS total_salary,
    AVG(salary) AS avg_salary,
    MAX(salary) AS max_salary,
    MIN(salary) AS min_salary
FROM cmdev.emp
GROUP BY job;
```

考點：

-   `GROUP BY`
-   `SUM`
-   `AVG`
-   `MAX`
-   `MIN`

SELECT

# 49. 考前必背語法模板

## 查詢

``` sql
SELECT 欄位
FROM 資料表
WHERE 條件
GROUP BY 欄位
HAVING 群組條件
ORDER BY 欄位 DESC
LIMIT 筆數;
```

## 新增

``` sql
INSERT INTO table_name(col1, col2)
VALUES(value1, value2);
```

## 修改

``` sql
UPDATE table_name
SET column = value
WHERE 條件;
```

## 刪除

``` sql
DELETE FROM table_name
WHERE 條件;
```

## 建表

``` sql
CREATE TABLE table_name (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    value DECIMAL(10,2) DEFAULT 0
);
```

## 分組

``` sql
SELECT 分組欄位, 聚合函數(欄位)
FROM 資料表
GROUP BY 分組欄位;
```

## CASE

``` sql
CASE
    WHEN 條件1 THEN 結果1
    WHEN 條件2 THEN 結果2
    ELSE 其他結果
END
```

## 交易

``` sql
START TRANSACTION;

UPDATE / DELETE ...

COMMIT;
```

或：

``` sql
ROLLBACK;
```

# 51. 一頁式口訣

``` text
查詢：
SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT

WHERE：
篩原始資料

HAVING：
篩分組結果

COUNT(*)：
全部資料列

COUNT(column)：
忽略 NULL

NULL：
IS NULL，不是 = NULL

字串：
LEFT / RIGHT / SUBSTRING
CONCAT / CONCAT_WS

數字：
ROUND 四捨五入
TRUNCATE 直接截斷
CEIL 向上
FLOOR 向下

主鍵：
不可重複 + 不可 NULL

AUTO_INCREMENT：
自動編號

UPDATE / DELETE：
一定先檢查 WHERE

交易：
START TRANSACTION
→ 修改
→ COMMIT 確認
→ ROLLBACK 復原
```
