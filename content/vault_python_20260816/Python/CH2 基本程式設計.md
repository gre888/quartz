## 1. `print()` 輸出函式

### 1.1 基本語法

``` python
print(value1, value2, ..., sep=' ', end='\n')
```

  參數      功能                     預設值
  --------- ------------------------ -------------
  `value`   要輸出的資料，可放多筆   ---
  `sep`     多筆資料之間的分隔字串   `' '` 空白
  `end`     輸出結束後加上的字串     `'\n'` 換行

### 1.2 基本範例

``` python
print('Python', 3.8)
# Python 3.8

print('台北', '台中', '台南', sep=',')
# 台北,台中,台南

print('高雄', '屏東', sep='\t')
# 高雄    屏東

print('價目表：', end='')
money = 30
print('陽春麵', money, '元')
# 價目表：陽春麵 30 元
```

### 考試重點

-   `sep`：控制「資料與資料之間」。
-   `end`：控制「輸出最後」。
-   `end=''`：輸出後不換行。
-   `print()` 可以一次輸出字串、數字、變數等多種資料。

# 2. `%` 格式化輸出

舊式格式化語法：

``` python
print('格式字串' % 引數)
print('格式字串' % (引數1, 引數2, ...))
```

基本格式：

``` text
%[修飾字元][寬度][.小數位數]型別字元
```

## 2.1 常用型別字元

  格式         用途           範例
  ------------ -------------- -------------------
  `%c`         單一字元       `'%c' % 'A'`
  `%s`         字串           `'%s' % 'Python'`
  `%d`、`%i`   十進位整數     `'%d' % 123`
  `%o`         八進位         `'%o' % 12`
  `%x`         十六進位小寫   `'%x' % 12`
  `%X`         十六進位大寫   `'%X' % 12`
  `%f`         浮點數         `'%.2f' % 12.345`
  `%e`         科學記號小寫   `'%e' % 123.4`
  `%E`         科學記號大寫   `'%E' % 123.4`
  `%%`         顯示 `%`       `'100%%'`

範例：

``` python
print('%c%s先生' % ('張', '無忌'))
# 張無忌先生

wt, price = 30, 20.5
print('%s%d斤,共%f元' % ('香蕉', wt, wt * price))
# 香蕉30斤,共615.000000元
```

------------------------------------------------------------------------

## 2.2 寬度與對齊

``` python
print('%8d' % 12345)
#    12345

print('%-8d' % 12345)
# 12345   

print('%08d' % 12345)
# 00012345
```

重點：

-   `%8d`：總寬度 8，預設靠右。
-   `%-8d`：總寬度 8，靠左。
-   `%08d`：總寬度 8，不足部分補 `0`。
-   如果資料本身超過設定寬度，Python 仍會完整顯示。

------------------------------------------------------------------------

## 2.3 小數位數

``` python
print('%f' % 12345.67)
# 12345.670000

print('%.2f' % 12.345)
# 12.35

print('%8.2f' % -12.3456)
#   -12.35
```

`%8.2f`：

-   `8`：總寬度。
-   `.2`：小數 2 位。
-   `f`：浮點數。

### 字串也能限制顯示字數

``` python
print('%6.2s' % 'ABCDE')
#     AB
```

代表總寬度 6，但字串只取前 2 個字元。

------------------------------------------------------------------------

## 2.4 修飾字元

  修飾字元   功能
  ---------- ----------------
  `#`        顯示進位前綴
  `0`        前面補 `0`
  `-`        靠左對齊
  空白       正數前保留一格

``` python
print('%#x' % 12345)
print('%08d' % 12345)
print('%-8d' % 12345)
print('% d' % 12345)
```

# 4. 整數 `int`

Python 整數可以使用不同進位表示。

``` python
print(12)       # 十進位
print(0b1100)   # 二進位
print(0o14)     # 八進位
print(0xC)      # 十六進位
```

以上數值都代表十進位的 `12`。

## 4.1 進位前綴

  進位       前綴   範例
  ---------- ------ ----------
  二進位     `0b`   `0b1100`
  八進位     `0o`   `0o14`
  十進位     無     `12`
  十六進位   `0x`   `0xC`

## 4.2 進位轉換函式

``` python
print(bin(12))   # '0b1100'
print(oct(12))   # '0o14'
print(hex(12))   # '0xc'
```

注意：`bin()`、`oct()`、`hex()` 回傳的是**字串**。

## 4.3 字串與整數的差異

``` python
print('12' * 4)
# 12121212

print(int('12') * 4)
# 48
```

這是很重要的考題：

-   `'12'` 是 `str`，乘 4 代表重複 4 次。
-   `int('12')` 是整數 `12`，乘 4 才是數學運算。

# 5. 浮點數 `float`

``` python
print(12.345)
print(1.2345e2)
print(1.2345e8)
print(1.2345e-2)
```

科學記號：

``` text
1.2345e2 = 1.2345 × 10²
1.2345e-2 = 1.2345 × 10⁻²
```

## 5.1 `float()`、`is_integer()`、`round()`

``` python
f, i = 1.2345, 12345

f2 = float(i)
print(f2)
# 12345.0

print(float.is_integer(f))
# False

print(float.is_integer(f2))
# True

print(round(f, 2))
# 1.23

print(round(f))
# 1
```

### `float.is_integer()`

判斷浮點數的小數部分是否為 0。

``` python
(12345.0).is_integer()   # True
(1.2345).is_integer()    # False
```

### `isinstance()`

``` python
print(isinstance(f2, int))
# False
```

雖然 `f2` 的值是 `12345.0`，但資料型別仍是 `float`。

# 6. 布林值 `bool`

Python 的布林值：

``` python
True
False
```

``` python
b = False
print(type(b))
# <class 'bool'>
```

## 6.1 `bool()` 型別轉換

``` python
print(bool(1))         # True
print(bool(-1))        # True
print(bool('Python'))  # True
```

常用判斷概念：

  值          `bool()`
  ----------- ----------
  `0`         `False`
  `0.0`       `False`
  `''`        `False`
  非 0 數字   `True`
  非空字串    `True`

另外：

``` python
print(int(False))   # 0
print(int(True))    # 1
```

所以在數值運算中，可以理解為：

``` text
False → 0
True  → 1
```

# 7. 自動型別運算

上課範例：

``` python
b, i, f = True, 2, 3.4

print(b+i, b+f, i+f)
print(b-i, b-f, i-f)
print(b*i, b*f, i*f)
print(b/i, b/f, i/f)
```

因為 `True` 在數值運算中可視為 `1`：

``` python
True + 2
# 3

True * 3.4
# 3.4
```

整數和浮點數一起計算時，結果通常會轉成 `float`：

``` python
2 + 3.4
# 5.4
```

# 10. `decimal` 精確小數運算

上課程式：

``` python
import decimal

d1 = decimal.Decimal.from_float(123.4567)
d2 = decimal.Decimal.from_float(34.5678)

print(d1 + d2)

print(decimal.getcontext())
print(decimal.getcontext().prec)
print(decimal.getcontext().rounding)

decimal.getcontext().prec = 8
print(d1 + d2)
```

## 重要觀念

### `Decimal.from_float()`

將 `float` 轉成 `Decimal`：

``` python
decimal.Decimal.from_float(123.4567)
```

### `getcontext().prec`

控制 Decimal 運算的精度：

``` python
decimal.getcontext().prec = 8
```

代表將運算精度設定為 8 位有效數字。

### `getcontext().rounding`

查看目前 Decimal 的捨入模式。

# 11. 算術運算

上課以圓與球體計算為例：

``` python
r = 6.4
PI = 3.14159

print('圓面積=', PI * r**2)
print('圓周長=', 2 * PI * r)
print('半徑=', r)
print('球的體積=', 4/3 * PI * r**3)
```

公式：

``` text
圓面積 = π × r²
圓周長 = 2 × π × r
球體積 = 4/3 × π × r³
```

### `**` 次方運算子

``` python
r ** 2   # r 的平方
r ** 3   # r 的三次方
```

# 13. 邏輯運算子

三個主要邏輯運算子：

``` python
and
or
not
```

## 13.1 `and`

兩邊條件都成立才成立。

``` python
True and True
# True

True and False
# False
```

## 13.2 `or`

只要其中一個條件成立即可。

``` python
False or True
# True
```

## 13.3 `not`

將真假反轉。

``` python
not True
# False

not False
# True
```

------------------------------------------------------------------------

## 13.4 `and`、`or` 不一定回傳 `True` / `False`

上課範例：

``` python
print(2 and 3)
# 3

print(2 or 3)
# 2

print('a' or 'b')
# a

print(0 and 3)
# 0

print('' or 'b')
# b
```

記憶：

-   `A and B`：A 為假就回傳 A；否則回傳 B。
-   `A or B`：A 為真就回傳 A；否則回傳 B。

因此：

``` python
2 and 3
```

`2` 是 truthy，所以繼續看 `3`，結果為 `3`。

``` python
0 and 3
```

`0` 是 falsy，因此直接得到 `0`。

# 14. 成員運算子 `in` / `not in`

用來判斷資料是否存在於字串、串列等容器中。

``` python
print('p' in 'pytho')
# True

print('x' not in 'python')
# True

print(1 in [1, 2, 3])
# True

print(2 not in [1, 2, 3])
# False
```

  運算子     意義
  ---------- ------------
  `in`       是否存在
  `not in`   是否不存在

# 15. 位元運算 Bitwise

上課範例：

``` python

print(5 ^ 3)
print(~5)
```

先轉成二進位：

``` text
5 = 0101

```

## 15.1 AND `&`

``` text
0101
0011
----
0001
```

``` python
5 & 3
# 1
```

## 15.2 OR `|`

``` text
0101
0011
----
0111
```

``` python
5 | 3
# 7
```

## 15.3 XOR `^`

相同為 0，不同為 1：

``` text
0101
0011
----
0110
```

``` python
5 ^ 3
# 6
```

## 15.4 NOT `~`

``` python
~5
# -6
```

Python 整數的位元反相可用下式記：

``` text
~n = -(n + 1)
```

因此：

``` text
~5 = -(5 + 1) = -6
```

# 18. 容易混淆的地方

## ① `'12' * 4` vs `int('12') * 4`

``` python
'12' * 4
# '12121212'

int('12') * 4
# 48
```

原因：第一個是字串重複，第二個是整數乘法。

## ② `int()` vs `round()`

``` python
int(12.8)    # 12
round(12.8)  # 13
```

`int()` 去除小數部分；`round()` 做捨入。

## ③ `12345.0` 不等於 `int` 型別

``` python
f = 12345.0

f.is_integer()
# True

isinstance(f, int)
# False
```

`is_integer()` 是判斷「這個 float 是否代表整數值」，不是判斷資料型別。

## ④ `and` / `or` 的結果可能不是布林值

``` python
2 and 3     # 3
2 or 3      # 2
'' or 'b'   # 'b'
```

## ⑤ `True` 可以參與數值運算

``` python
True + 2
# 3
```

因為：

``` python
int(True)   # 1
int(False)  # 0
```

# 21. 新增上課範例：`print()`、變數與字串

## 21.1 `%` 格式化與引數串列

``` python
print('汽水2打24瓶')
print('汽水%d打24瓶' % 2)

dozen = 2
print('%s%d打%d瓶' % ('汽水', dozen, dozen * 12))
```

三行都會得到：

``` text
汽水2打24瓶
```

重點：

-   `%s`：字串。
-   `%d`：十進位整數。
-   多個引數寫成：`% (資料1, 資料2, ...)`。
-   引數可以是常值、變數，也可以是 `dozen * 12` 這種運算式。

------------------------------------------------------------------------

## 21.2 逸出序列實作

``` python
print('1234567890!\a')
print('12345\b67890!')
print('1234567890!\n')
print('123\r456789!')
print('123\t4567')
print('12\\3\'45\"')
```

  寫法   作用
  ------ ------------
  `\a`   系統提示音
  `\b`   Backspace
  `\n`   換行
  `\r`   回到行首
  `\t`   Tab
  `\\`   顯示 `\`
  `\'`   顯示 `'`
  `\"`   顯示 `"`

最常考：

``` text
\n  → 換行
\t  → Tab
\\  → 顯示反斜線
```

> `\a`、`\b`、`\r` 的實際效果可能因終端機而不同。


  格式     意義
  -------- ---------------------
  `%#x`    十六進位，顯示 `0x`
  `%08d`   寬度 8，不足補 `0`
  `%-8d`   寬度 8，靠左

## 21.4 浮點數格式化

``` python
print('%f' % 12345.67)
print('%f' % -12.345)
print('%.2f' % 12.345)
print('%8.2f' % -12.3456)
print('%3.1f' % 123.45)
print('%8.0f' % -1234.56)
print('%8.0f' % 1234.56)
print('%E' % 1234567.89)
print('%e' % 123.4)
print('%10.2e' % 12345.6)
print('%10.2e' % 0.000123456)
```

必記：

``` text
%f       → 浮點數，預設小數 6 位
%.2f     → 小數 2 位
%8.2f    → 總寬度 8、小數 2 位
%8.0f    → 總寬度 8、不顯示小數
%e       → 小寫科學記號
%E       → 大寫科學記號
%10.2e   → 總寬度 10、科學記號小數 2 位
```

例如：

``` python
print('%f' % 12345.67)
# 12345.670000

print('%.2f' % 12.345)
# 12.35
```

## 21.5 整數、字元與字串寬度

``` python
print('%d' % 12345)
print('%8d' % 12345)
print('%-8d' % 12345)
print('%08d' % 12345)
print('%3d' % -12345)

print('%c' % 'A')
print('%4c' % 'A')
print('%c' % 65)

print('%s' % 'ABCDE')
print('%8s' % 'ABCDE')
print('%3s' % 'ABCDE')
print('%6.2s' % 'ABCD')
```

### 整數

``` text
%8d   → 寬度 8，靠右
%-8d  → 寬度 8，靠左
%08d  → 寬度 8，補 0
```

如果資料比設定寬度更長：

``` python
print('%3d' % -12345)
```

仍然完整顯示：

``` text
-12345
```

### `%c`

``` python
print('%c' % 'A')
print('%c' % 65)
```

都會顯示：

``` text
A
```

`65` 對應字元 `A`。

### `%6.2s`

``` python
print('%6.2s' % 'ABCD')
```

表示：

-   總寬度 6。
-   最多顯示 2 個字元。
-   因此只顯示 `AB`，不足寬度在前方補空格。

## 21.6 多個格式化資料

``` python
print('%c%s 先生' % ('張', '無際'))

wt, price = 3, 20.5
print('%s%d斤,共%f元' % ('香蕉', wt, wt * price))
```

`wt * price` 會先計算：

``` text
3 × 20.5 = 61.5
```

因為 `%f` 預設 6 位小數：

``` text
香蕉3斤,共61.500000元
```

## 21.7 `print()` 的 `sep` 與 `end`

``` python
print('python', 3.8)
print('台北', '台中', '台南', sep=',')
print('高雄', '屏東', sep='\t')

print('價目表:', end='')
money = 30
print('陽春麵', money, '元')
```

### `sep`

控制「多筆資料之間」：

``` python
print('台北', '台中', '台南', sep=',')
# 台北,台中,台南
```

### `end`

控制「print 最後」：

``` python
print('價目表:', end='')
print('陽春麵', 30, '元')
# 價目表:陽春麵 30 元
```

快速記憶：

``` text
sep → separate → 資料之間
end → ending   → 最後面
```

# 23. 字串索引與切片

範例：

``` python
flavor = "fig pie"
```

索引：

``` text
字元：   f   i   g       p   i   e
正索引： 0   1   2   3   4   5   6
負索引：-7  -6  -5  -4  -3  -2  -1
```

索引 `3` 是空白。

## 23.1 切片基本語法

``` python
字串[start:stop]
```

規則：

> **包含 start，不包含 stop，也就是「左含右不含」。**

------------------------------------------------------------------------

## 23.2 正索引切片

``` python
print(flavor[0:3])   # fig
print(flavor[3:7])   # " pie"
print(flavor[3:])    # " pie"
print(flavor[:])     # fig pie
print(flavor[:14])   # fig pie
print(flavor[13:15]) # 空字串
```

重要觀念：

-   `[: ]`：整個字串。
-   `[3:]`：從索引 3 到最後。
-   `[:3]`：從頭到索引 3 前面。
-   切片終點超出字串範圍通常不會報錯。
-   `flavor[13]` 這種單一索引超出範圍則會 `IndexError`。

------------------------------------------------------------------------

# 24. 負索引切片

``` python
print(flavor[-7:-4]) # fig
print(flavor[-7:0])  # 空字串
print(flavor[-7:])   # fig pie
print(flavor[-3:])   # pie
```

常用技巧：

``` python
text[:3]   # 前 3 個字元
text[-3:]  # 後 3 個字元
text[:]    # 全部
```

### 為什麼 `flavor[-7:0]` 是空字串？

`-7` 與 `0`
都指向字串最前方的位置，而切片預設方向是由左往右，因此沒有字元可以取得。

# 25. 字串不可直接修改：Immutable

``` python
word = "goal"

# 錯誤：
# word[0] = "f"
```

Python 的 `str` 是不可變物件，不能直接修改某個索引位置。

可以建立新字串：

``` python
word = "f" + word[1:]
print(word)
# foal
```

過程：

``` text
word[1:]       → "oal"
"f" + "oal"    → "foal"
```

所以這不是修改原字串，而是建立新字串後重新指派。

# 29. 新增內容易錯題

## ① `sep` vs `end`

``` python
print('A', 'B', 'C', sep='-')
# A-B-C
```

``` python
print('A', end='')
print('B')
# AB
```

## ② 切片左含右不含

``` python
text = 'python'
print(text[1:4])
# yth
```

取得索引 `1、2、3`，不包含索引 `4`。

## ③ 正索引與負索引

``` text
字串：   p   y   t   h   o   n
正索引： 0   1   2   3   4   5
負索引：-6  -5  -4  -3  -2  -1
```

``` python
'python'[0]   # p
'python'[-1]  # n
```

## ④ 字串 immutable

錯誤：

``` python
word[0] = 'f'
```

正確：

``` python
word = 'f' + word[1:]
```

## ⑤ `del` 後不能再使用

``` python
x = 10
del x
print(x)
```

會產生 `NameError`。

## ⑥ `%f` vs `%.2f`

``` python
print('%f' % 12.3)
# 12.300000

print('%.2f' % 12.3)
# 12.30
```

## ⑦ `%c` 與字碼

``` python
print('%c' % 65)
# A
```
