## 1. if / elif / else vs 巢狀 if（超級常考）

### 核心口訣

- **`if` + `elif`**：前面條件不成立，**才**檢查下一個 → 同一層，多選一，只會執行其中一段
- **`if` 裡面縮排一個 `if`（巢狀 if）**：外層成立**之後**，才有資格判斷內層 → 兩層都要成立才會進到最裡面
- **兩個各自獨立的 `if`**：兩個都會各自判斷一次，彼此互不影響（例如 `##3` 那題，兩個獨立 if，第二個的 else 只屬於第二個 if）

### 由高到低 / 由低到高判斷的技巧

python

```python
if grade >= 90:      # 先排除最高的
    A
elif grade >= 80:    # 前面已經排除 90 以上
    B
elif grade >= 70:
    C
else:
    F
```

判斷順序是「由上往下」，前面條件成立後面就不會再檢查，所以不需要寫 `grade >= 80 and grade <= 89`。

### 判斷 None 要放最前面

python

```python
if age == None:      # 一定要先擋掉 None，否則 None < 13 會 TypeError
    ...
elif age < 13:
    ...
elif age < 18:
    ...
else:
    ...
```

### 縮排決定一切

看到題目要你排列程式片段時，**先看縮排再看條件**：

- 兩個 `if` 垂直對齊（同一層）→ 用 `elif`
- 第二個 `if` 縮排在第一個裡面 → 巢狀 if，且通常會需要外層先篩選一次條件（例如先判斷 `age >= 5`，內層才判斷 `age <= 17`）

## 2. 迴圈（while / for / for...else）

### while 迴圈 + 布林旗標（flag）樣板 — 非常常考

python

```python
valid = False        # 每一輪都要重新設 False，代表先假設不合法

if len(parts) == 2:
    if len(parts[0]) == 2 and len(parts[1]) == 4:
        if parts[0].isdigit() and parts[1].isdigit():
            valid = True   # 全部條件過關才改 True
```

口訣：**「先 False，全部檢查通過才改成 True。」**

### Sentinel（哨兵）迴圈

python

```python
product_no = ""                      # 初始值必須讓 while 條件成立
while product_no != "sentinel":      # 直到輸入 sentinel 才停止（也可能是判斷空字串）
    ...
    product_no = input(...)
```

- 迴圈開始前的**初始值**要讓 while 第一次判斷為 `True`
- 若一開始就把變數設成跟結束條件一樣的值，迴圈根本不會執行 → 這是常見陷阱

### 質數判斷（while + for + break）

python

```python
n = 2
while n <= 100:
    is_prime = True          # ★ 每一輪都要重設，放在 while 裡面

    for i in range(2, n):
        if n % i == 0:
            is_prime = False
            break             # ★ 找到因數就沒必要再檢查下去

    if is_prime == True:
        print(n)

    n += 1                    # ★ 忘記加會變成無窮迴圈
```

### for...else（極度常考，容易跟 if...else 搞混）

python

```python
for i in range(len(items)):
    if items[i] == term:
        print("found")
        break
else:
    print("not found")
```

**規則：**

- `else` 和 `for` 對齊（不是跟 if 對齊）
- **for 正常跑完、沒被 break 中斷 → 執行 else**
- **中途 break → 不執行 else**

比較表：

|結構|else 何時執行|
|---|---|
|if...else|if 條件為 False|
|for...else|for 沒被 break 中斷，正常跑完|
|while...else|while 沒被 break 中斷，正常結束|

### range() 重點

- `range(a, b)`：**包含 a，不包含 b**
- 例：`range(1, 6)` → 1,2,3,4,5（共 5 次，常用來做「5 列」的迴圈）
- 例：`range(1, 5)` → 1,2,3,4（共 4 次）

## 3. 函式（function）

### 預設參數 / 位置引數 / 關鍵字引數

python

```python
def getpay(hours=40, rate=25, qty=0, qtyrate=0, salary=0):
```

- 全部有預設值 → `getpay()` 可以直接呼叫，不會出錯
- **位置引數**：照順序對應（`func(10, 20)`）
- **關鍵字引數**：用參數名稱對應，順序可以任意換（`func(b=20, a=10)`）
- 呼叫時的變數名稱不需要跟函式參數名稱相同，Python 是**依照位置**配對
- 關鍵字引數名稱如果拼錯（函式沒有這個參數名）→ `TypeError`
- 用了函式外沒有定義過的變數當引數 → `NameError`

### pass 不等於 return（超級常考陷阱）

python

```python
if salary > 0:
    pass     # 什麼都不做，繼續往下執行，不會結束函式！
```

- `pass`：什麼都不做，程式繼續往下跑
- `return`：回傳值，並且**立刻結束函式**，後面的程式碼不會執行

### 沒有 return 的函式

- 函式裡只有 `print()` 沒有 `return` → 呼叫後不會回傳明確的值（隱含回傳 `None`）
- 分清楚：`print()` 是顯示畫面用；`return` 才是把值傳出去

### Docstring（文件字串）

python

```python
def cube(n):
    """Returns the cube of number n"""   # 三個雙引號，放在函式標頭正下方第一行
    return n * n * n

print(cube.__doc__)   # 用 函式名稱.__doc__ 印出文件字串（注意前後都是兩個底線）
```

口訣：**三引號 → 函式第一行 → `.__doc__`**

### 一般註解 vs docstring

- 單行註解：`# 這是註解`
- 文件字串：`""" ... """`
- `//`、`/* */`、單引號沒收尾 都不是 Python 合法註解

## 4. 字串 / 索引 / format

### 索引與長度

- 字串長度是 `len()`，但**最後一個字元的索引是 `len() - 1`**（索引從 0 開始）

python

```python
length = len(backward_name) - 1
while length >= 0:
    forward_name += backward_name[length]
    length -= 1
```

（等效寫法：`backward_name[::-1]`）

### split() + isdigit()（驗證格式常考）

python

```python
parts = "12-3456".split("-")     # ["12", "3456"]
len(parts) == 2                  # 是否切成兩段
parts[0].isdigit()                # 是否全部是數字
```

### str.format() 索引規則（重要陷阱）

python

```python
x, y, z = "oranges", "apples", "bananas"
data = "{1} and {0} and {2}"
print(data.format(z, y, x))
```

`{0}, {1}, {2}` 對應的是 **`.format()` 括號裡參數的順序**，跟變數本身叫什麼名字無關：

- `.format(z, y, x)` → `{0}=z, {1}=y, {2}=x`
- 結果：`apples and bananas and oranges`

### input() 一定回傳字串

python

```python
base = input("...")      # 永遠是 str，即使輸入 "123" 也是字串 "123"
```

- 字串不能做 `**`、數學運算（`"2" ** "3"` → `TypeError`）
- 要轉型：`int(input())` 或 `float(input())`
- `str + int` 也會出錯，要用 `str(result)` 或改用逗號 `print("結果", result)` / f-string

## 5. 布林值 / 比較運算子

python

```python
0 or 5          # → 5   （or 回傳「第一個 truthy 值」，不是回傳 True/False）
bool(0)         # → False
None is None    # → True （is 判斷是否為同一物件）
-5 < 0 < 5      # → True （Python 支援連鎖比較，等同 (-5<0) and (0<5)）
```

陷阱提醒：**truthy 不代表運算結果就是 `True`**，`0 or 5` 結果是整數 `5`。

`or` / `and` 判斷技巧：

- 「任何一個符合就好」→ 用 `or`
- 「兩個都要符合」→ 用 `and`
- 比較是否相等用 `==`，指派用 `=`，判斷是否為 None 用 `is None`

## 9. try / except / finally

python

```python
try:
    process()
except:
    logError()
finally:
    displayResult()
```

- `try`：嘗試執行
- `except`：發生例外時執行
- `finally`：**不管有沒有發生例外都會執行**（幾乎必定執行）
- `raise`：主動拋出例外；`assert`：條件不成立時丟出 `AssertionError`（這兩個不是這個流程的一部分，考試常拿來當干擾選項）

## 10. unittest

python

```python
import unittest

class TestIsInstance(unittest.TestCase):        # 一定要繼承 unittest.TestCase

    def test_isInstance(self):                  # 方法名稱要以 test 開頭，且要有 self
        self.assertIsInstance(obj, cls)          # 前面一定要加 self.

if __name__ == "__main__":
    unittest.main()
```

- `assertIsInstance(obj, cls)`：檢查 `obj` 是不是 `cls` 的實例
- 跟一般函式 `isinstance(obj, cls)`（直接回傳 True/False）不同，`assert...` 系列是 **TestCase 的斷言方法**，測試不成立就算「失敗」
- 常見 assert 系列口訣：**Equal 比值、Is 比身分、In 看包含、IsInstance 看類型**
- 大小寫要注意：`assertIsInstance`（I 大寫），不是 `assertisInstance`

## 11. 考前速記 Top 10 陷阱

1. `elif` 判斷是「前面不成立才看」；巢狀 `if` 是「前面成立才看」——順序完全相反，題目常互換考。
2. `pass` ≠ `return`，`pass` 之後程式繼續往下跑。
3. `input()` 永遠回傳字串，做運算前記得 `int()` / `float()`。
4. `range(a, b)` 不包含 b。
5. `for...else` 的 `else` 是跟 `for` 對齊，「沒被 break 才執行」。
6. `while` 迴圈裡如果有「重設旗標」（如 `is_prime = True`、`valid = False`），一定要放在迴圈**裡面**，每輪重設，否則邏輯會壞掉。
7. `"a"` 附加模式不會清空檔案，`"w"` 才會覆寫。
8. `.format()` 的索引 `{0}{1}{2}` 看的是 `.format()` 括號裡的順序，不是變數宣告順序。
9. `len()` 給的是長度，最後一個索引永遠是 `len()-1`。
10. 關鍵字引數名稱打錯 → `TypeError`；用了未定義的變數 → `NameError`，兩者要分清楚。

## Python ITS 考試重點整理

### 1. `if / elif / else`：先看縮排

這是你這份題目裡非常重要的考點。

```
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"
```

記住：

|寫法|意思|
|---|---|
|`if + if`|兩個條件獨立，第二個一定還會判斷|
|`if + elif`|前面不成立，才判斷下一個|
|`if + else`|`if` 不成立就執行 `else`|
|巢狀 `if`|第一關成立後，才進第二關|

尤其考題不要看到第二個條件就直接認為是 `elif`，**先看縮排層級**。

例如：

```
if age >= 5:
    if student:
        fee = 60
```

內層 `if` 只有在 `age >= 5` 成立後才會判斷。

---

### 2. `and / or / not`

```
A and B
```

→ **兩個都 True 才 True**

```
A or B
```

→ **至少一個 True 就 True**

```
not A
```

→ True / False 反轉。

德摩根定律：

```
not (A and B) = (not A) or (not B)
not (A or B)  = (not A) and (not B)
```

考題特別注意：

```
age >= 5 and school
```

兩個條件都成立才會進去。

### 3. `while`：條件成立就一直跑

```
n = 1

while n <= 5:

輸出：

```
1
2
3
4
5
```

最重要陷阱：

```
n += 1
```

如果該增加計數器卻忘記寫，條件可能永遠成立，造成**無窮迴圈**。

### 4. `for`、`range()`、`in`

基本結構：

```
for 變數 in 可迭代物件:
    ...
```

例如：

```
for char in "ABC":

輸出：

```
A
B
C

```
range(start, stop, step)
```

其中 **stop 不包含**。

```
range(1, 5)
```

得到：

```
1, 2, 3, 4
```

### 5. `break` 與 `continue`

```
break
```

→ **直接離開目前迴圈**

```
continue
```

→ **跳過本輪剩下程式，進下一輪**

例如質數題：

```
if n % i == 0:
    is_prime = False
    break
```

已經找到因數，就確定不是質數，不必繼續檢查。

你的題目特別強調質數程式的三個陷阱：`is_prime = True` 每輪要重設、找到因數後 `break`、最後 `n += 1` 避免無窮迴圈。

### 6. `for ... else` 是 ITS 很愛考的陷阱

```
for x in data:
    if 找到了:
        break
else:
    print("找不到")
```

記：

**找到 → `break` → 不執行 `else`**

**沒找到 → `for` 正常跑完 → 執行 `else`**

而且 `else` 是跟 `for` 配對，不一定是跟 `if` 配對。

### 7. 字串 / List 索引：從 `0` 開始

```
text = "Python"
```

```
P y t h o n
0 1 2 3 4 5
```

所以：

```
len(text)       # 6
text[0]         # P
text[5]         # n
text[-1]        # n
```

超重要公式：

> **最後一個索引 = `len() - 1`**

如果寫：

```
text[len(text)]
```

會超出範圍，造成 `IndexError`。

反轉：

```
text[::-1]
```

### 9. `input()` 永遠先得到字串

這是非常重要的陷阱：

```
x = input()
```

`x` 是：

```
str
```

要數學運算：

```
x = int(input())
```

或：

```
x = float(input())
```

例如：

```
"答案：" + 8
```

❌ `str + int` → `TypeError`

可以：

```
"答案：" + str(8)
```

或：

```
print("答案：", 8)
```

或：

```
print(f"答案：{8}")
```

### 10. 函式：位置引數 vs 關鍵字引數

```
def roomAssignment(student, year):
    pass
```

位置引數：

```
roomAssignment("Tom", 4)
```

依**位置**配對。

關鍵字引數：

```
roomAssignment(student="Tom", year=4)
```

依**參數名稱**配對。

混合：

```
roomAssignment("Tom", year=4)
```

也合法。

你之前問的「有沒有 `=`」可以當快速判斷：

```
"Tom"        → 位置引數
year=4       → 關鍵字引數
```

但 `=` 左邊必須是函式真正的參數名稱。

### 11. 預設參數

```
def petStore(category, species, breed="none"):
    pass
```

代表：

```
category → 必填
species  → 必填
breed    → 選填
```

因此：

```
petStore("dog", "Canine")
```

合法，`breed` 自動使用 `"none"`。

關鍵字引數順序可以改：

```
petStore(
    breed="Maltese",
    species="Canine",
    category="dog"
)
```

也是合法。

### 12. `return`、`print`、`pass`

這三個一定分清楚：

print(x)

```
return x

→ 回傳結果，並且**立即結束函式**。

```

### 14. 註解

```
# comment
```

不是：

```
// comment
```

```

```

### 15. 例外處理

標準結構：

```
try:
    process()
except:
    logError()
finally:
    displayResult()
```

記：

```
try      → 嘗試執行
except   → 發生例外時執行
finally  → 不管有沒有例外通常都會執行
```

常考錯誤：

```
TypeError
```

→ 型態不適合，例如：

```
"5" + 3
```

```
ValueError
```

→ 型態轉換內容不合法：

```
int("abc")
```

```
ZeroDivisionError
```

→ 除以 0：

```
10 / 0
```

```
IndexError
```

→ 索引超出範圍。

```
NameError

### 19. `unittest`

基本架構：

```
import unittest

class TestType(unittest.TestCase):

    def test_number(self):
        x = 100
        self.assertIsInstance(x, int)

if __name__ == "__main__":
    unittest.main()
```

你目前 ITS 題目建議背：

```
assertEqual(a, b)       → 值是否相等
assertIs(a, b)          → 是否為同一物件
assertIn(a, b)          → a 是否存在 b 裡
assertIsInstance(a, T)  → a 是否為 T 型態/類別的實例
```

而測試方法通常必須以：

```
test_
```

開頭，才會被測試執行器自動找到。
