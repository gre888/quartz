# Python 布林值與 `if` 判斷重點案例

## 一、布林值是什麼？

Python 的布林值只有兩種：

- `True`：條件成立
- `False`：條件不成立

`if` 會根據條件是 `True` 還是 `False`，決定是否執行縮排內的程式。

```python
if 條件:
    # 條件為 True 時執行
```

## 案例一：CSV 檔案不存在才寫入標題

### 完整程式

```python
import csv
import os

data = [
    {"品名": "台積電", "股價": 800, "評等": "買進"},
    {"品名": "聯發科", "股價": 1000, "評等": "持有"},
    {"品名": "鴻海", "股價": 150, "評等": "買進"}
]

file_name = "stocks.csv"
fieldnames = ["品名", "股價", "評等"]

# 檔案不存在時為 True；檔案存在時為 False
file_not_exists = not os.path.exists(file_name)

with open(file_name, mode="a", encoding="utf-8-sig", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames)

    if file_not_exists:
        writer.writeheader()

    writer.writerows(data)
```

### 判斷重點

```python
file_not_exists = not os.path.exists(file_name)
```

| 檔案狀態 | `os.path.exists(file_name)` | `file_not_exists` |
|---|---:|---:|
| 檔案不存在 | `False` | `True` |
| 檔案已存在 | `True` | `False` |

接著判斷：

```python
if file_not_exists:
    writer.writeheader()
```

- `file_not_exists` 是 `True`：執行 `writeheader()`。
- `file_not_exists` 是 `False`：跳過 `writeheader()`。

因此，CSV 標題只會在第一次建立檔案時寫入，不會在每次執行時重複。

> 注意：必須在 `open()` 之前判斷檔案是否存在，因為 `"a"` 模式會自動建立不存在的檔案。

## 案例二：搜尋學生資料

### 完整程式

```python
students = [
    {"id": "A01", "name": "Alice", "score": 85},
    {"id": "A02", "name": "Bob", "score": 92},
    {"id": "A03", "name": "Charlie", "score": 78}
]

s = 0

for data in students:
    s = s + data["score"]

print("Average score:", s / len(students))

search_id = input("Enter student ID to search: ")

# 搜尋前先假設沒有找到
found = False

for data in students:
    if data["id"] == search_id:
        print("Student found:", data)
        found = True
        break

if not found:
    print("Student not found.")
```

### 判斷重點

搜尋開始前：

```python
found = False
```

代表目前還沒有找到學生。

搜尋過程中：

```python
if data["id"] == search_id:
    found = True
    break
```

如果學生編號相同：

1. 將 `found` 改成 `True`，表示已經找到。
2. `break` 立即結束 `for` 迴圈。
3. `break` 不會把 `found` 改回 `False`。

搜尋完成後：

```python
if not found:
    print("Student not found.")
```

`not` 會把布林值反轉：

| `found` | `not found` | 是否顯示找不到 |
|---:|---:|---|
| `True` | `False` | 不顯示 |
| `False` | `True` | 顯示 `Student not found.` |

## 兩個案例比較

| 案例 | 布林變數 | 初始值／取得方式 | 何時為 `True` | `if` 的作用 |
|---|---|---|---|---|
| CSV 寫入標題 | `file_not_exists` | 檢查檔案是否不存在 | 檔案不存在 | 寫入標題列 |
| 搜尋學生 | `found` | 一開始設定為 `False` | 找到相同學生編號 | 記錄已找到學生 |

## 最重要的觀念

### 1. `if 變數`

變數為 `True` 時才執行：

```python
if file_not_exists:
    writer.writeheader()
```

### 2. `if not 變數`

變數為 `False` 時才執行：

```python
if not found:
    print("Student not found.")
```

### 3. 指定與比較不同

```python
found = True       # 將 True 指定給 found
found == True      # 比較 found 是否等於 True
```

一般判斷時，建議直接寫：

```python
if found:
    print("已找到")
```

不需要寫成：

```python
if found == True:
    print("已找到")
```

## 快速記憶

```python
if found:
```

意思是：「如果已找到」。

```python
if not found:
```

意思是：「如果沒有找到」。

```python
if file_not_exists:
```

意思是：「如果檔案不存在」。
