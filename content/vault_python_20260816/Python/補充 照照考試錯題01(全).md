### 第 (2) 題：取得星期名稱

答案：

```
today = now.strftime("%A")
```

所以：

> **(2) A**

`%A` 代表：

> **星期的完整英文名稱**

例如：

```
now.strftime("%A")
```

可能得到：

```
"Monday"
"Friday"
"Saturday"
"Sunday"
```

這樣才能跟下面比較：

```
if today == "Friday" or today == "Saturday" or today == "Sunday":
```

常考的可以記：

|格式|意義|例子|
|---|---|---|
|`%A`|星期完整名稱|`Sunday`|
|`%a`|星期縮寫|`Sun`|
|`%B`|月份完整名稱|`September`|
|`%Y`|四位數年份|`2026`|

### 第 (3) 題：計算離星期日還有幾天

答案：

```
daysLeft = 6 - now.weekday()
```

所以：

> **(3) B**

Python 的：

```
now.weekday()
```

規則是：

```
Monday    → 0
Tuesday   → 1
Wednesday → 2
Thursday  → 3
Friday    → 4
Saturday  → 5
Sunday    → 6
```

因此用：

```
6 - now.weekday()
```

例如今天是 Friday：

```
now.weekday()
# 4
```

所以：

```
6 - 4
# 2
```

代表距離 Sunday 還有 2 天。

### 最後答案

> **✅ (1) A　(2) A　(3) B**

可以直接記成：

```
datetime.datetime.now()   # 現在時間

strftime("%A")            # 星期完整英文名稱

weekday()                  # 星期一=0 ～ 星期日=6
```

這三個是 `datetime` 題目很常一起考的組合。
這題的關鍵是這一行：

```
file_out = open("out.txt", "w+")
```

題目特別說：

> **`out.txt` 檔案不存在時執行程式**

`"w+"` 模式的特性是：**檔案不存在就自動建立；檔案存在則清空原內容後重新寫入。**

所以單純因為 `out.txt` 不存在，**不會發生錯誤**。

因此答案是：

|選項|Yes / No|原因|
|---|---|---|
|A. 程式正常執行，不會發生錯誤|✅ **Yes**|`"w+"` 會自動建立 `out.txt`|
|B. 執行但產生邏輯錯誤|❌ **No**|沒有因 `out.txt` 不存在造成邏輯問題|
|C. 產生執行階段錯誤|❌ **No**|`"w+"` 不要求檔案事先存在|
|D. 產生語法錯誤|❌ **No**|程式語法本身合法|

> **✅ 最終答案：A Yes、B No、C No、D No**

這題建議記住檔案模式：

```
open("out.txt", "r")    # 讀取；檔案不存在 → 錯誤
open("out.txt", "w")    # 寫入；不存在 → 建立
open("out.txt", "w+")   # 讀寫；不存在 → 建立
open("out.txt", "a")    # 附加；不存在 → 建立
```

### `"w+"` 最重要的兩件事

```
不存在 → 建立新檔案
已存在 → 清空原內容
```

所以這題一看到：

```
open("out.txt", "w+")
```

配上：

> `out.txt` 不存在

就可以直接判斷：

> **沒關係，Python 會幫你建立。→ A Yes**

另外，程式中的：

```
except IOError:
    print('cannot open', file_name)
```

確實有一個潛在問題：`file_name` 並沒有先定義；**但只有真的進入 `except` 時才會碰到這個問題**。本題只說 `out.txt` 不存在，而 `"w+"` 可以建立它，所以這不是本題答案的重點。
