# Python 考試重點整理

## 1. `if / elif / else` 條件判斷

### 成績等級：由高往低判斷

``` python
if grade >= 90:
    letter_grade = "A"
elif grade >= 80:
    letter_grade = "B"
elif grade >= 70:
    letter_grade = "C"
elif grade >= 60:
    letter_grade = "D"
else:
    letter_grade = "F"
```

**重點：** - 第一個條件用 `if`，中間用 `elif`，最後用 `else`。 - Python
由上往下判斷。 - 前面成立後，後面的 `elif` 不再判斷。 -
`elif grade >= 80` 已代表 80～89，因為 90 以上已被排除。

------------------------------------------------------------------------

## 2. `None` 要先處理

``` python
if age == None:
    rating = "未知"
elif age < 13:
    rating = "普遍級"
elif age < 18:
    rating = "輔導級"
else:
    rating = "限制級"
```

若 `age = None`，直接做 `age < 13` 會造成 `TypeError`。

**口訣：未知 → 普 → 輔 → 限**

> 實務 Python 通常推薦 `if age is None:`；考試依選項作答。

------------------------------------------------------------------------

## 3. 兩個 `if` 不等於 `if...elif`

``` python
if grade > 80 and rank >= 3:
    grade += 10

if grade > 70 and rank > 3:
    grade += 5
else:
    grade -= 5
```

兩個 `if` 是獨立判斷，`else` 只和第二個 `if` 配對。

例如 `grade = 76`、`rank = 3`，最後結果為 **71**。

**必記：**

``` text
if + if + else
```

與

``` text
if + elif + else
```

完全不同。

------------------------------------------------------------------------

## 4. 巢狀 `if`：先看縮排

``` python
if a < 0:
    answer = "negative"
else:
    if a > 0:
        answer = "positive"
    else:
        answer = "zero"
```

**考試技巧：先看縮排，再看條件。**

縮排可判斷 `else` 屬於哪一個 `if`。

------------------------------------------------------------------------

## 5. Python 沒有 `else if`

錯誤：

``` python
else if grade >= 80:
```

正確：

``` python
elif grade >= 80:
```

**`else if` ❌　`elif` ✅**

------------------------------------------------------------------------

## 6. `and`：兩個條件都要成立

``` python
if grade > 80 and rank >= 3:
```

只有 `True and True` 才是 `True`。

例如：

``` text
76 > 70 and 3 > 3
True and False → False
```

------------------------------------------------------------------------

## 7. `while` 質數題：必考結構

``` python
n = 2

while n <= 100:
    is_prime = True

    for i in range(2, n):
        if n % i == 0:
            is_prime = False
            break

    if is_prime == True:
        print(n)

    n += 1
```

### 三大考點

1.  `is_prime = True` 放在 `while` 裡，每輪重新設定。
2.  找到因數後 `break`，因為已確定不是質數。
3.  `n += 1` 不可漏，否則可能造成無窮迴圈。

**口訣：每輪重設 True → 找因數 → 找到設 False → break → n + 1**

------------------------------------------------------------------------

## 8. `for...else` 特殊結構

``` python
for i in range(len(nums)):
    if nums[i] > num:
        print("找到")
        break
else:
    print("找不到")
```

這個 `else` 是和 `for` 配對。

-   找到 → `break` → 不執行 `else`
-   全部找完、沒有 `break` → 執行 `else`

------------------------------------------------------------------------

## 9. Sentinel Loop（哨兵迴圈）

``` python
product_no = "sentinel"

while product_no != "":
    valid = False
    product_no = input("Enter product number: ")
```

`"sentinel"` 只是普通字串，用來讓第一次 `while product_no != ""` 成立。

使用者直接按 Enter，使 `product_no = ""`，下一輪條件為 False，迴圈停止。

**哨兵值 = 用特殊值控制迴圈何時停止。**

------------------------------------------------------------------------

## 10. 布林旗標變數 Flag

``` python
valid = False
```

檢查成功：

``` python
valid = True
```

質數題：

``` python
is_prime = True
```

找到因數：

``` python
is_prime = False
```

-   `True` → 成立／找到／有效
-   `False` → 不成立／沒找到／無效

------------------------------------------------------------------------

## 11. `split()` + `isdigit()`

``` python
product_no = "12-3456"
parts = product_no.split("-")
```

結果：

``` python
["12", "3456"]
```

檢查：

``` python
if len(parts) == 2:
    if len(parts[0]) == 2 and len(parts[1]) == 4:
        if parts[0].isdigit() and parts[1].isdigit():
            valid = True
```

-   `split("-")`：依 `-` 分割
-   `len()`：檢查長度
-   `isdigit()`：檢查是否全部為數字

## 12. 函式預設參數

``` python
def getpay(hours=40, rate=25, qty=0, qtyrate=0, salary=0):
    pass
```

所有參數都有預設值，因此：

``` python
getpay()
```

可以直接呼叫。

也可以：

``` python
getpay(qty=500, qtyrate=4)
```

其他參數使用預設值。

## 13. 關鍵字引數順序可以改

``` python
def petStore(category, species, breed="none"):
    pass
```

以下合法：

``` python
petStore(
    breed="Maltese",
    species="Canine",
    category="dog"
)
```

-   位置引數 → 看位置
-   關鍵字引數 → 看名稱
-   關鍵字引數順序可以改，但名稱必須正確

## 14. `pass`、`return`、`break` 差異

``` text
pass   → 什麼都不做，繼續往下
return → 回傳結果，立即結束函式
break  → 結束目前所在的迴圈
```

### `pass`

``` python
if salary > 0:
    pass
```

### `return`

``` python
return qty * qtyrate
```

### `break`

``` python
break
```

------------------------------------------------------------------------

## 15. 沒有寫 `return` 的函式

``` python
def test():
    print("Hello")
```

沒有明確 `return` 時，Python 會隱含回傳 `None`。

``` python
x = test()
print(x)
```

結果：

``` text
Hello
None
```

**`print()` = 顯示資料；`return` = 回傳資料。**

## 17. Docstring 三問

### ① 用什麼？

三個雙引號：

``` text
"""文件說明"""
```

### ② 放哪裡？

函式定義後的第一個敘述：

``` python
def cube(n):
    """Returns the cube of number n"""
    return n ** 3
```

### ③ 怎麼取得？

``` python
print(cube.__doc__)
```

**口訣：三引號 → 函式第一行 → `.__doc__`**

## 18. `random` 必考函式

``` python
import random
```

### `randint(a, b)`

``` python
random.randint(1, 10)
```

產生 1～10 的整數，**1 和 10 都包含**。

### `choice()`

``` python
random.choice(groupList)
```

從清單中隨機選一個元素。

### `shuffle()`

``` python
random.shuffle(groupList)
```

將整個清單順序隨機打亂。

**快速記憶：**

``` text
randint → 隨機整數
choice  → 選一個
shuffle → 洗牌
```

## 19. `datetime` 三個必考

``` python
import datetime

now = datetime.datetime.now()
today = now.strftime("%A")
number = now.weekday()
```

`weekday()` 規則：

``` text
Monday    → 0
Tuesday   → 1
Wednesday → 2
Thursday  → 3
Friday    → 4
Saturday  → 5
Sunday    → 6
```

距離星期日：

``` python
daysLeft = 6 - now.weekday()
```

------------------------------------------------------------------------

## 20. `strftime()` 常考格式

  格式   意義           例子
  ------ -------------- -------------
  `%A`   星期完整名稱   `Sunday`
  `%a`   星期縮寫       `Sun`
  `%B`   月份完整名稱   `September`
  `%Y`   四位數年份     `2026`

**特別記：`%A` → 星期完整英文名稱。**

## 21. 檔案模式 `r / w / w+ / a`

  模式   讀取   寫入   檔案不存在
  ------ ------ ------ -------------
  `r`    ✅     ❌     ❌ 發生錯誤
  `w`    ❌     ✅     ✅ 建立
  `w+`   ✅     ✅     ✅ 建立
  `a`    ❌     ✅     ✅ 建立

### `r`

``` python
open("data.txt", "r")
```

不存在會發生錯誤。

### `w`

``` python
open("data.txt", "w")
```

不存在 → 建立；已存在 → 清空原內容。

### `w+`

``` python
open("out.txt", "w+")
```

可讀可寫；不存在 → 建立；已存在 → 清空。

### `a`

``` python
open("data.txt", "a")
```

不存在 → 建立；已存在 → 從最後面追加。

# 考試最容易出錯的 10 個陷阱

1.  `if` + `if` 是兩次獨立判斷。
2.  `else` 要看縮排，判斷它屬於哪個 `if`。
3.  Python 沒有 `else if`，要用 `elif`。
4.  `break` = 結束目前迴圈。
5.  `return` = 回傳結果並結束函式。
6.  `pass` = 什麼都不做，繼續執行。
7.  `for...else`：沒有執行 `break` 才會執行 `else`。
8.  `is_prime`、`valid` 等旗標變數常需要每輪重新設定。
9.  關鍵字引數順序可改，但名稱必須正確。
10. `w`、`w+` 檔案不存在會建立；`r` 不會。

------------------------------------------------------------------------
