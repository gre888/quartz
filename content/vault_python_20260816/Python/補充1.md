## 1. `print()` 與字串連接

### 基本輸出

``` python
print("Hello")
print(123)
print("Python")
```

### 使用 `+` 連接

`+` 連接文字時，左右兩邊都必須是字串 `str`。

``` python
name = "Tom"
print("Hello " + name)
```

數字不能直接與字串用 `+` 連接：

``` python
age = 20
print("年齡：" + age)       # TypeError
print("年齡：" + str(age))  # 正確
```

### `+`、`,`、f-string 比較

  寫法                      數字需 `str()`   特點
  ------------------------- ---------------- ----------------------------
  `"年齡：" + str(age)`     是               字串連接
  `print("年齡：", age)`    否               `print()` 自動處理不同型別
  `print(f"年齡：{age}")`   否               最簡潔、推薦

``` python
name = "Tom"
age = 20

print("姓名：" + name + " 年齡：" + str(age))
print("姓名：", name, "年齡：", age)
print(f"姓名：{name} 年齡：{age}")
```

### `sep` 控制分隔符號

``` python
print("Tom", 20, 95, sep="-")
# Tom-20-95

print("2026", "09", "01", sep="/")
# 2026/09/01
```

### `+` 的兩種作用

``` python
10 + 20       # 30，數字加法
"10" + "20"   # "1020"，字串連接
```

### `input()` 重點

`input()` 回傳的資料預設是字串。

``` python
name = input("姓名：")
print("你好，" + name)
```

若先轉成整數：

``` python
age = int(input("年齡："))
print("年齡：" + str(age))
# 或
print("年齡：", age)
```

**記憶：`+` 連文字時兩邊都要是 `str`；`,` 與 f-string
不需要手動轉字串。**

## 2. List / Dict 巢狀結構

### 最重要觀念

-   `List []`：使用「索引」取值，例如 `[0]`
-   `Dict {}`：使用「Key」取值，例如 `["name"]`

### List 裡放 Dict

``` python
students = [
    {"name": "Tom", "score": 80},
    {"name": "Mary", "score": 95}
]

print(students[1]["name"])   # Mary
print(students[1]["score"])  # 95
```

### Dict 裡放 List

``` python
student = {
    "name": "Tom",
    "scores": [80, 90, 75]
}

print(student["scores"][1])  # 90
```

### Dict 裡放 Dict

``` python
student = {
    "name": "Tom",
    "score": {
        "python": 90,
        "mysql": 85
    }
}

print(student["score"]["python"])  # 90
```

### List → Dict → List

``` python
students = [
    {"name": "Tom", "scores": [80, 90, 100]},
    {"name": "Mary", "scores": [95, 88, 92]}
]

print(students[1]["scores"][1])  # 88
```

讀法：

``` text
students → 第 2 筆 → scores → 第 2 筆
```

### List → Dict → Dict

``` python
students = [
    {
        "name": "Mary",
        "scores": {
            "python": 95,
            "mysql": 88
        }
    }
]

print(students[0]["scores"]["mysql"])  # 88
```

### 考試判斷技巧

看到：

``` python
data[0]["students"][1]["score"]
```

依序判斷：

``` text
[0]          → List 索引
["students"] → Dict Key
[1]          → List 索引
["score"]    → Dict Key
```

**口訣：`[]` 裡是數字通常是在取 List；`[]` 裡是字串 Key 通常是在取
Dict。**

## 3. 常見錯誤：TypeError、ValueError、ZeroDivisionError

  錯誤                  中文理解   常見原因
  --------------------- ---------- --------------------------
  `TypeError`           型別錯誤   資料型別不適合操作
  `ValueError`          值錯誤     型別可接受，但內容不合法
  `ZeroDivisionError`   除以 0     除數為 0

### TypeError

``` python
age = 20
print("年齡：" + age)
```

`str + int` 無法直接相加。

### ValueError

``` python
age = int("abc")
```

`int()` 可以接受字串，但 `"abc"` 無法轉成整數。

### ZeroDivisionError

``` python
print(10 / 0)
```

### TypeError vs ValueError

``` python
int([1, 2, 3])  # TypeError：型別不適合
int("ABC")      # ValueError：型別可接受，但值不合法
```

**口訣：Type 看型別；Value 看內容；ZeroDivision 看除數是否為 0。**

## 4. Python 註解 `#`

### 單行註解

``` python
# 這是註解
```

Python 會忽略 `#` 後面的內容。

### 引號裡的 `#` 不是註解

``` python
comment = "# Return the value"
```

這裡的 `#` 是字串內容。

### 行尾註解

``` python
return x ** y  # 回傳 x 的 y 次方
```

### 考試重點

-   Python 不執行 `#` 後面的註解內容。
-   單行註解需要 `#`。
-   `"# Hello"` 是字串，不是註解。
-   程式碼後面可以接行尾註解。

## 5. `unittest` 與常見斷言

### 基本結構

``` python
import unittest

class TestIsInstance(unittest.TestCase):

    def test_isInstance(self):
        obj = 10
        self.assertIsInstance(obj, int)

if __name__ == "__main__":
    unittest.main()
```

### 結構重點

1.  `import unittest`
2.  測試類別繼承 `unittest.TestCase`
3.  測試方法名稱以 `test` 開頭
4.  斷言方法前使用 `self.`
5.  `unittest.main()` 執行測試

### 常見斷言比較

  方法                         實際比較               用途
  ---------------------------- ---------------------- ------------------
  `assertEqual(a, b)`          `a == b`               值是否相等
  `assertIs(a, b)`             `a is b`               是否為同一個物件
  `assertIn(a, b)`             `a in b`               是否包含
  `assertIsInstance(a, cls)`   `isinstance(a, cls)`   是否為指定型別

### `assertEqual` vs `assertIs`

``` python
a = [1, 2]
b = [1, 2]

a == b   # True
a is b   # False
```

**口訣：Equal 比值、Is 比身分、In 看包含、IsInstance 看型別。**

## 6. `sort()` 與 `sorted()`

最重要差異：

> `sort()` 修改原本的 list；`sorted()` 不修改原資料，而是回傳新的 list。

  比較         `list.sort()`    `sorted()`
  ------------ ---------------- --------------------------
  類型         List 方法        內建函式
  修改原資料   會               不會
  回傳值       `None`           新的 List
  可處理資料   主要是 List      List、Tuple、Set、字串等
  反向排序     `reverse=True`   `reverse=True`

### `sort()`

``` python
nums = [5, 2, 8, 1]
result = nums.sort()

print(nums)    # [1, 2, 5, 8]
print(result)  # None
```

### `sorted()`

``` python
nums = [5, 2, 8, 1]
result = sorted(nums)

print(nums)    # [5, 2, 8, 1]
print(result)  # [1, 2, 5, 8]
```

### 反向排序

``` python
nums.sort(reverse=True)
result = sorted(nums, reverse=True)
```

### Tuple

``` python
data = (5, 2, 8, 1)
result = sorted(data)
# 回傳 [1, 2, 5, 8]
```

Tuple 沒有 `.sort()`。

**口訣：`sort()` 改自己；`sorted()` 生新的。**

## 7. 字串反轉與 `range()`

### 切片反轉

``` python
name = "Python"
print(name[::-1])
# nohtyP
```

切片格式：

``` python
資料[start:stop:step]
```

`[::-1]` 表示從尾端開始，每次往前 1 格。

### `for + range()` 反轉

``` python
name = "Python"

for index in range(len(name)-1, -1, -1):
    print(name[index])
```

`name` 長度為 6，因此：

``` python
range(5, -1, -1)
```

產生：

``` text
5, 4, 3, 2, 1, 0
```

### 為什麼 stop 是 `-1`？

因為 `range()` 的 `stop` **不包含**。

``` python
range(5, -1, -1)
```

才會跑到 `0`。

### `name[-1]` 與 `range(..., -1, -1)` 不同

``` python
name[-1]
```

這個 `-1` 是「負索引」，代表最後一個字元。

``` python
range(5, -1, -1)
```

-   第一個 `-1`：停止位置（不包含）
-   第二個 `-1`：步進，每次減 1

**不要把負索引的 `-1` 與 `range()` 參數的 `-1` 混在一起。**

## 8. `pass`、`continue`、`break`

### `pass`

`pass` = 什麼都不做，只是讓語法保持完整。

``` python
def login():
    pass

class Student:
    pass
```

也可放在 `if`、`for`、`while` 中。

### 三者比較

  語法         意思         對迴圈的影響
  ------------ ------------ --------------
  `pass`       什麼都不做   繼續正常往下
  `continue`   跳過本次     進入下一輪
  `break`      結束迴圈     整個迴圈停止

``` python
for i in range(5):
    if i == 2:
        pass
    print(i)
# 0 1 2 3 4
```

``` python
for i in range(5):
    if i == 2:
        continue
    print(i)
# 0 1 3 4
```

``` python
for i in range(5):
    if i == 2:
        break
    print(i)
# 0 1
```

**口訣：pass 什麼都不做；continue 這一圈不要；break 全部停止。**

## 9. `while`、`break`、`continue`

### 基本 `while`

``` python
i = 1

while i <= 5:
    print(i)
    i += 1
```

只要條件為 `True` 就持續執行。

### `while + break`

``` python
i = 1

while i <= 5:
    if i == 3:
        break
    print(i)
    i += 1
```

輸出：

``` text
1
2
```

`break` 會直接結束整個迴圈。

### `while + continue`

``` python
i = 0

while i < 5:
    i += 1

    if i == 3:
        continue

    print(i)
```

輸出：

``` text
1
2
4
5
```

### `continue` 的無限迴圈陷阱

錯誤：

``` python
i = 1

while i <= 5:
    if i == 3:
        continue

    print(i)
    i += 1
```

當 `i == 3` 時會一直 `continue`，導致 `i` 永遠沒有增加。

較安全的寫法：

``` python
i = 0

while i < 5:
    i += 1

    if i == 3:
        continue

    print(i)
```

## 10. `while True` 與 `while False`

### `while True`

代表條件永遠成立，因此通常形成無限迴圈，要搭配 `break`。

``` python
while True:
    num = int(input("輸入數字，0 結束："))

    if num == 0:
        break

    print("你輸入：", num)
```

### `while False`

``` python
while False:
    print("Hello")
```

條件一開始就是 `False`，所以迴圈一次都不會執行。

### 使用布林變數控制

``` python
running = True

while running:
    num = int(input("輸入數字，0 結束："))

    if num == 0:
        running = False
    else:
        print(num)
```

當 `running = False` 後，下一次條件判斷就會結束迴圈。
