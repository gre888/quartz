## 1. `sys.argv` 命令列參數

### 範例

執行：

```bash
python Script.py Cheese Bacon Bread
```

Python 會把程式檔名和命令列輸入內容存入 `sys.argv` 串列：

```python
sys.argv[0] = "Script.py"
sys.argv[1] = "Cheese"
sys.argv[2] = "Bacon"
sys.argv[3] = "Bread"
```

因此：

```python
sys.argv[2]
```

答案是：

```text
Bacon
```

### 完整程式

```python
import sys

print(sys.argv)
print(sys.argv[2])
```

### 考試重點

- `sys.argv[0]` 是執行的程式檔名。
- 使用者輸入的第一個參數從 `sys.argv[1]` 開始。
- `sys.argv` 中的資料都是字串。
- 使用前必須先 `import sys`。

> 口訣：`[0]` 放檔名，真正輸入從 `[1]` 開始。

## 2. 位置引數與關鍵字引數

假設函式定義如下：

```python
def roomAssignment(student, year=3):
    print(student, year)
```

其中：

- `student` 是必要參數。
- `year` 的預設值是 `3`。

### 呼叫方式比較

| 呼叫方式 | 結果 | 原因 |
|---|---:|---|
| `roomAssignment(name, year=grade)` | ✅／❌ | `name`、`grade` 已定義就可以；未定義會發生 `NameError` |
| `roomAssignment("Sherlock", 4)` | ✅ | 使用位置引數，依序傳給 `student`、`year` |
| `roomAssignment(student, year)` | ✅／❌ | 兩個變數已定義就可以；未定義會發生 `NameError` |
| `roomAssignment(year=6, name="Minnie")` | ❌ | 函式沒有名為 `name` 的參數，會發生 `TypeError` |

### 位置引數：依照位置配對

```python
roomAssignment("Sherlock", 4)
#               ↓          ↓
#            student      year
```

位置引數的順序不能放錯。

### 關鍵字引數：依照參數名稱配對

```python
roomAssignment(year=4, student="Sherlock")
```

關鍵字引數的順序可以交換，但名稱必須和函式定義完全一致。

### 使用預設值

```python
roomAssignment("Sherlock")
```

因為沒有提供 `year`，所以會使用預設值 `3`。

> 口訣：位置引數看順序；關鍵字引數看名稱。

## 3. 使用 `while` 判斷質數

### 什麼是質數？

質數是大於 `1`，而且只能被 `1` 和自己整除的整數，例如：

```text
2、3、5、7、11……
```

### 找出 2～10 的質數

```python
n = 2

while n <= 10:                    # 外層：依序檢查每一個 n
    is_prime = True                # 先假設目前的 n 是質數
    divisor = 2                    # 從 2 開始尋找因數

    while divisor < n:             # 內層：檢查 n 是否能被整除
        if n % divisor == 0:
            is_prime = False       # 找到因數，所以不是質數
            break                  # 離開內層 while

        divisor = divisor + 1      # 改用下一個除數

    if is_prime:
        print(n)

    n = n + 1                      # 改檢查下一個數字
```

輸出：

```text
2
3
5
7
```

### 程式結構

1. 外層 `while`：依序換成 `2、3、4……10`。
2. `is_prime = True`：每次先假設新的 `n` 是質數。
3. 內層 `while`：尋找能整除 `n` 的因數。
4. 找到因數：把 `is_prime` 改成 `False`，再用 `break` 停止搜尋。
5. 沒有找到因數：`is_prime` 保持 `True`，印出 `n`。
6. `n = n + 1`：換下一個數字。

### 三個重要角色

| 程式 | 作用 | 若省略可能發生什麼事？ |
|---|---|---|
| `is_prime = True` | 每輪重新假設目前的 `n` 是質數 | 前一輪的 `False` 可能影響下一輪 |
| `break` | 找到因數後，立刻離開內層迴圈 | 結果通常不變，但會繼續做不必要的檢查 |
| `n = n + 1` | 讓外層迴圈改檢查下一個數字 | `n` 不變，形成無窮迴圈 |

### 為什麼 `is_prime = True` 要放在外層迴圈內？

例如檢查 `4` 時找到因數 `2`：

```python
is_prime = False
```

下一輪檢查 `5` 時，必須重新設定：

```python
is_prime = True
```

否則上一輪留下的 `False` 會使程式錯誤地把 `5` 當成非質數。

### 用 `n = 5` 實際追蹤

| divisor | 判斷 | 結果 |
|---:|---|---|
| 2 | `5 % 2 == 0` | `False`，繼續 |
| 3 | `5 % 3 == 0` | `False`，繼續 |
| 4 | `5 % 4 == 0` | `False`，繼續 |
| 5 | `5 < 5` | `False`，內層迴圈結束 |

因為沒有找到任何因數，`is_prime` 仍是 `True`，所以印出 `5`。

### 用 `n = 6` 實際追蹤

```python
6 % 2 == 0
```

條件成立，表示 `2` 是 `6` 的因數：

```python
is_prime = False
break
```

程式已經確定 `6` 不是質數，因此不必再檢查 `3、4、5`。

> 口訣：外層換數字，內層找因數；找到就 `break`，最後用 `n + 1` 換下一個。

## 4. `raise`：主動拋出例外

主動拋出例外的關鍵字是：

```python
raise
```

### 基本語法

```python
raise 例外類型("錯誤訊息")
```

### 範例：檢查年齡

```python
age = -5

if age < 0:
    raise ValueError("年齡不能小於 0")

print("程式繼續執行")
```

結果：

```text
ValueError: 年齡不能小於 0
```

例外沒有被處理時，程式會中斷，因此最後的 `print()` 不會執行。

### 搭配 `try...except`

```python
try:
    age = -5

    if age < 0:
        raise ValueError("年齡不能小於 0")

except ValueError as e:
    print("發生錯誤：", e)

print("程式繼續執行")
```

輸出：

```text
發生錯誤： 年齡不能小於 0
程式繼續執行
```

### 成績檢查範例

```python
score = 120

if score < 0 or score > 100:
    raise ValueError("成績必須在 0～100 之間")
```

### 考試重點

- `raise`：主動丟出例外。
- `except`：捕捉並處理例外。
- `raise` 後面通常接例外類型和錯誤訊息。

> 口訣：`raise` 負責丟，`except` 負責接。

## 5. Docstring 文件字串

### Docstring 三問

| 問題 | 答案 |
|---|---|
| 用什麼符號？ | 通常使用三個雙引號 `"""..."""` |
| 放在哪裡？ | 模組、函式、類別內容中的第一個敘述 |
| 如何查看？ | 使用 `物件.__doc__` 或 `help(物件)` |

### 函式 Docstring 範例

```python
def add(a, b):
    """計算兩個數字相加的結果。"""
    return a + b

print(add.__doc__)
```

輸出：

```text
計算兩個數字相加的結果。
```

也可以使用：

```python
help(add)
```

### 位置很重要

```python
def add(a, b):
    """必須是函式內容中的第一個敘述。"""
    return a + b
```

若字串不是第一個敘述，就不會成為該函式的正式 Docstring。

### Docstring 與普通註解的差別

```python
# 這是普通註解，Python 不會把它存入 __doc__。

def add(a, b):
    """這是 Docstring，可以透過 __doc__ 查看。"""
    return a + b
```

### 補充

Docstring 也能使用三個單引號：

```python
'''這也是合法的 Docstring。'''
```

不過 Python 慣例通常使用三個雙引號。

> 考試速記：三個雙引號、放第一個敘述、用 `__doc__` 或 `help()` 查看。

## 6. `:=` 海象運算子

`:=` 稱為海象運算子，也叫做「指定運算式」。它可以在運算式中：

1. 將值指定給變數。
2. 立刻使用這個值。

### 基本範例

```python
print(a := 3)
print(a)
```

輸出：

```text
3
3
```

執行過程：

```text
a := 3
→ 把 3 存入 a
→ 此運算式的值也是 3
→ print() 印出 3
```

### 單獨使用時要加括號

```python
a := 3       # SyntaxError
```

應改為：

```python
(a := 3)
print(a)
```

一般單純指定值時，直接使用 `=` 會更清楚：

```python
a = 3
```

### `=` 與 `:=` 比較

| 符號 | 名稱 | 功能 |
|---|---|---|
| `=` | 指定運算子 | 將值存入變數 |
| `:=` | 海象運算子 | 在運算式中指定值，並立刻使用該值 |

### 搭配 `while` 使用

```python
while (name := input("姓名：")) != "exit":
    print("你好", name)
```

執行範例：

```text
姓名：Tom
你好 Tom
姓名：Mary
你好 Mary
姓名：exit
```

這一行可以拆成四個步驟：

```python
while (name := input("姓名：")) != "exit":
```

1. `input()` 取得使用者輸入。
2. `:=` 將輸入內容存入 `name`。
3. 將 `name` 與 `"exit"` 比較。
4. 不是 `exit` 就執行迴圈；是 `exit` 就結束。

> 口訣：`:=` 等於「指定值＋立即使用」。
