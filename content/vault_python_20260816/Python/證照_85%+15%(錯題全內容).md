## ##1 ------------------------ 
```
# Letter Grade Converter

grade = int(input("Enter a numeric grade"))

if grade >= 90:
    letter_grade = 'A'
elif grade >= 80:
    letter_grade = 'B'
elif grade >= 70:
    letter_grade = 'C'
elif grade >= 60:
    letter_grade = 'D'
else:
    letter_grade = 'F'

print("Your letter grade is :", letter_grade)
```

這題是在考 **`if / elif / else` 的區間判斷**。
依照表格：
- 90～100 → A
- 80～89 → B
- 70～79 → C
- 60～69 → D
- 0～59 → F

因此答案是：

|題號|答案|原因|
|---|---|---|
|(1)|**B. `if grade >= 90:`**|90 分以上是 A|
|(2)|**D. `elif grade >= 80:`**|前面已排除 90 以上，所以這裡就是 80～89|
|(3)|**D. `elif grade >= 70:`**|前面已排除 80 以上，所以這裡就是 70～79|
|(4)|**D. `elif grade >= 60:`**|前面已排除 70 以上，所以這裡就是 60～69|

所以：
```
(1) B
(2) D
(3) D
(4) D
```
這題最重要的觀念是：**`elif` 會按照「由上往下」判斷，而且前面的條件成立後，後面的就不再執行。**
例如輸入：
```
grade = 89
```
判斷流程是：
```
if grade >= 90:      # 89 >= 90 → False
elif grade >= 80:    # 89 >= 80 → True
```
所以得到：
```
B
```
也因此不需要寫成：
```
elif grade >= 80 and grade <= 89:
```
因為前面的 `grade >= 90` 已經幫你把 90 以上排除了。

可以把這種題型記成一個很重要的模板：
```
if 分數 >= 最高門檻:
    ...
elif 分數 >= 第二門檻:
    ...
elif 分數 >= 第三門檻:
    ...
else:
    ...
```
也就是 **「由高分往低分判斷」**。



## ##2 --------------------------------------------------

|年齡|電影分級|
|---|---|
|`age >= 18`|限制級|
|`13 <= age < 18`|輔導級|
|`age <= 12`|普遍級|
|`age == None`|未知|

### 正確答案
```
def get_rating(age):
    rating = ""

    if age == None:
        rating = "未知"
    elif age < 13:
        rating = "普遍級"
    elif age < 18:
        rating = "輔導級"
    else:
        rating = "限制級"

    return rating
```

這考 **`if / elif / else` 的判斷順序**，另外還要特別處理 `age == None`（年齡未知）。
所以選擇題答案是：

|題號|答案|
|---|---|
|(1)|**D** `age == None: rating="未知"`|
|(2)|**A** `age < 13: rating="普遍級"`|
|(3)|**B** `age < 18: rating="輔導級"`|
|(4)|**C** `: rating="限制級"`|

**答案：D、A、B、C**
### 為什麼一定要先判斷 `None`？
這是這題最重要的地方。
假設：
```
age = None
```
如果一開始就寫：
```
if age < 13:
```
Python 等於在做：
```
None < 13
```
這是不能比較的，會產生：
```
TypeError
```
所以必須先：
```
if age == None:
```
把「未知」處理掉。
### 為什麼 `age < 18` 就代表 13～17？
看執行順序：
```
if age == None:
    未知
elif age < 13:
    普遍級
elif age < 18:
    輔導級
else:
    限制級
```
例如 `age = 15`：
```
age == None → False
age < 13    → False
age < 18    → True
                  ↓
               輔導級
```
因為 `< 13` 已經在上一個條件排除了，所以：
```
elif age < 18:
```
實際上就是：
```
13 <= age < 18
```
這類考題可以記成圖片上的口訣：
**未知 → 普 → 輔 → 限**
```
None
 ↓
< 13
 ↓
< 18
 ↓
else
```
## ##3 --
```
if grade > 80 and rank >= 3:
    grade += 10

if grade > 70 and rank > 3:
    grade += 5
else:
    grade -= 5
```

這跟你上一題「成績 A、B、C、D、F」的概念是一樣的：**前面的 `if/elif` 已經幫後面的條件排除一部分範圍。**

已知：
```
grade = 76
rank = 3
```
逐步判斷：
**第一個 `if`：**
```
if grade > 80 and rank >= 3:
```
代入：
```
76 > 80 and 3 >= 3
False   and True
```
結果是 `False`，所以：
```
grade += 10
```
不執行，`grade` 還是 **76**。
**第二個 `if`：**
```
if grade > 70 and rank > 3:
```
代入：
```
76 > 70 and 3 > 3
True    and False
```
結果也是 `False`。
所以執行第二個 `if` 對應的 `else`：
```
else:
    grade -= 5
```
因此：
```
grade = 76 - 5
      = 71
```
所以這題其實答案是：
> **A. 71**
### ⚠️ 這題最容易掉進的陷阱
圖片上的紅字提醒非常重要：這裡有 **兩個獨立的 `if`**：
```
if 條件1:
    ...

if 條件2:
    ...
else:
    ...
```
這個 `else` **只屬於第二個 `if`**，不是第一個。
可以把它看成：
```
第一組
if 條件1
   ↓
結束

第二組
if 條件2
   ├─ True  → +5
   └─ False → -5
```
因此第一個 `if` 判斷完，**第二個 `if` 一定還會再判斷一次**。
所以最終答案：
**✅ A. 71**
> 補充：我開頭寫成「C. 81」是錯的；依程式逐行執行，正確答案是 **A. 71**。
## ##4 -----

```
def reResult(a):

    if a < 0:
        answer = "The result is a negative number"
    else:
        if a > 0:
            answer = "The result is a positive number"
        else:
            answer = "The result is a zero"

    return answer
```

### 為什麼這樣寫？
第一層先判斷：
```
if a < 0:
```
如果成立，代表是**負數**。
如果不成立：
```
else:
```
代表目前只剩下：
```
正數 或 0
```
所以進入 `else` 後，再做第二次判斷：
```
if a > 0:
```
成立 → 正數；不成立 → 只能是 0。
因此結是：
```
a < 0？
│
├── 是 → 負數
│
└── 否
     │
     └── a > 0？
          │
          ├── 是 → 正數
          │
          └── 否 → 0
```
### 這題最重要：縮排
注意圖片中的 `(3)`：
```
else:
    if a > 0:
```
第二個 `if` **縮排在第一個 `else` 裡面**，所以叫做「巢狀 if」。
可以記成：
> **先判斷負數 → 不是負數 → 再判斷正數 → 不是正數就是 0**
答案：
```
(1) A  if a < 0:
(2) C  else:
(3) B  if a > 0:
(4) C  else:
```
**✅ A、C、B、C**

## ##5 ----------------------

|條件|票價|
|---|---|
|5 歲以下|免費 0 元|
|5 歲以上，而且是學生|60 元|
|5～17 歲，而且不是學生|120 元|
|17 歲以上，而且不是學生|180 元|

依照題目的程式架構，完整程式應該是：
```
def ticket_fee(age, school):
    fee = 0

    if school:
        fee = 60
    else:
        if age < 17:
            fee = 120
        else:
            fee = 180

    return fee
```

這題的重點是 **巢狀 `if`（Nested if）**，而且可以從「縮排」判斷 `(2)` 跟 `(1)` 是同一層，`(3)` 則在 `(2)` 裡面。

但是這樣**沒有處理「5 歲以下免費」**，所以 `(1)` 應該還要把年齡條件一起考慮。依照題目的規則與版面結構，更合理的完整邏輯是：
```
def ticket_fee(age, school):
    fee = 0

    if age >= 5 and school:
        fee = 60
    elif age >= 5:
        if age < 17:
            fee = 120
        else:
            fee = 180

    return fee
```
### 執行流程
可以把它畫成：
```
fee = 0
  │
  ├─ age >= 5 且是學生？
  │      └─ 是 → 60 元
  │
  └─ age >= 5 且不是學生
         │
         ├─ age < 17 → 120 元
         │
         └─ else → 180 元
```
而 **5 歲以下**兩個條件都不成立，因此：
```
fee = 0
```
保持不變，也就是免費。

所以你這張圖最重要的判斷方式是：
```
(1)  第一層
(2)  第一層
    (3)  第二層 ← 注意縮排
    else 第二層
```
也就是：
```
if 條件1:          # (1)
    ...
elif 條件2:        # (2)
    if 條件3:      # (3)
        ...
    else:
        ...
```
**考試看到這種題目，先看「縮排」再看條件，通常會快很多。**
你圖片上寫的「正解應為 ACD，解答為 ACC？」這個疑問是對的。
依照程式邏輯，**正確答案應該是 A、C、D**，不是 A、C、C。

## ##6 ---

```
num = int(input("Enter a number with 1 or 2 digits: "))
digits = "0"

if num > 0:

    if num < 10:          # (1) A
        digits = "1"

    elif num < 100:       # (2) C
        digits = "2"

    else:                 # (3) D
        digits = ">2"

    print(digits + " digits.")

elif num == 0:
    print("The number is 0")

else:
    print("The number is not a positive number")
```

### 為什麼是 A、C、D？
先看正整數的三種情況：

|輸入|條件|結果|
|---|---|---|
|1～9|`< 10`|`"1"`|
|10～99|`< 100`|`"2"`|
|100 以上|前兩個都不成立|`">2"`|

所以結構必須是：
```
if num < 10:
    digits = "1"

elif num < 100:
    digits = "2"

else:
    digits = ">2"
```
因此：
```
(1) A → if num < 10:
(2) C → elif num < 100:
(3) D → else:
```
**答案：ACD**
---
### 為什麼 (3) 不能選 C？

如果選 C，程式會變成：
```
if num < 10:
    digits = "1"

elif num < 100:
    digits = "2"

elif num < 100:       # ← 完全重複
    digits = ">2"
```
例如：
```
num = 150
```
判斷：
```
150 < 10   → False
150 < 100  → False
150 < 100  → False
```
結果 `digits` 還是原本的：
```
digits = "0"
```
最後反而印出：
```
0 digits.
```
顯然不符合「100 以上 → 2 位數以上」的要求。
### 一個很好記的方法
這題就是典型的：
```
if 最小範圍:
    ...
elif 第二範圍:
    ...
else:
    剩下全部
```
也就是：
```
< 10？   → 1 位數
   ↓ 否
< 100？  → 2 位數
   ↓ 否
else     → 2 位數以上
```
所以如果題本或答案表寫 **ACC**，那很可能是**答案誤植**；依照圖片中的程式與題意，**ACD 才能正確完成程式**。

## ##7 ----
```
n = 2
while n <= 100:
    is_prime = True

    for i in range(2, n):
        if n % i == 0:
            is_prime = False
            break

    if is_prime == True:
        print(n)

    n += 1
```

這題非常重要，主要考 **巢狀迴圈 `while + for`、布林旗標 `is_prime`、`break`**，以及「`is_prime = True` 要放在哪裡」。
因此由上到下的程式片段是：
**B → G → C → E**

### 為什麼第一格是 B，不是 A？
A：
```
n = 2
is_prime = True

while n <= 100:
```
B：
```
n = 2

while n <= 100:
    is_prime = True
```
關鍵就在 `is_prime = True` 的位置。
我們檢查一個新的 `n`，都必須重新假設：
> 「這個數先當作是質數。」
所以必須放在 `while` 裡：
```
while n <= 100:
    is_prime = True
```
例如：
```
n = 2 → is_prime = True
n = 3 → is_prime = True
n = 4 → is_prime = True
n = 5 → is_prime = True
...
```
如果像 A 放在 `while` 外面，只執行一次。一旦遇到：
```
n = 4
```
發現：
```
4 % 2 == 0
```
就會：
```
is_prime = False
```
之後 `n = 5、6、7...` 都沒有重新變回 `True`，程式就錯了。

### 第二格為什麼是 G？
G：
```
for i in range(2, n):
    if n % i == 0:
        is_prime = False
```
它是在找：
> n 能不能被 2 到 n-1 之間的數整除？
例如 `n = 7`：
```
7 % 2 != 0
7 % 3 != 0
7 % 4 != 0
7 % 5 != 0
7 % 6 != 0
```
都不能整除，所以：
```
is_prime = True
```
因此 7 是質數。

---

### 第三格為什麼是 C：`break`？
當找到因數，就已經確定不是質數：
```
if n % i == 0:
    is_prime = False
    break
```
例如 `n = 12`：
```
i = 2
12 % 2 == 0
     ↓
is_prime = False
     ↓
break
```
已經知道 12 可以被 2 整除，就**不用繼續檢查 3、4、5……**。
所以：
```
break
```
意思是：
> **立即離開目前的 `for` 迴圈。**
---

### 最後一定要 E：`n += 1`
```
n += 1
```
就是：
```
n = n + 1
```
讓程式：
```
2 → 3 → 4 → 5 → 6 → ... → 100
```
如果沒有：
```
n += 1
```
那：
```
n
```
永遠都是 2：
```
2 → 2 → 2 → 2 → 2...
```
`while n <= 100` 永遠成立，就會變成**無窮迴圈**。

---

### 考試可以直接記這個結構
```
n = 2

while n <= 100:          # 外層：一個一個檢查數字

    is_prime = True      # ★ 每一輪重新設 True

    for i in range(2, n):  # 內層：找因數

        if n % i == 0:
            is_prime = False
            break         # ★ 找到因數就停止

    if is_prime == True:
        print(n)

    n += 1                # ★ 換下一個數字
```
所以這題三個最容易考的陷阱，可以記：
**① `is_prime = True` 要放在 `while` 裡，每輪重設。  
② `break` 是找到因數後，不必再檢查。  
③ `n += 1` 不可漏掉，否則會無窮迴圈。**
**✅ 最終排列：B → G → C → E**


## ##8 ---


```
def search(nums, num):

    for i in range(len(nums)):

        if nums[i] > num:
            print("A value greater than {0} is found in the list of {1}"
                  .format(num, nums))

            break

    else:
        print("A value greater than {0} cannot be found in the list of {1}"
              .format(num, nums))
```

這題主要考 **`for...else`、`break`，以及縮排的位置**。
正確排列是：
> **E → A → B → D → C**
組合後：
### 逐段看

**E：先定義函式**

```
def search(nums, num):
```

`nums` 是清單，`num` 是拿來比較的數字。

**A：使用 `for` 逐一檢查**

```
for i in range(len(nums)):
```

假設：

```
nums = [10, 20, 30, 40]
```

則：

```
i = 0 → nums[0] = 10
i = 1 → nums[1] = 20
i = 2 → nums[2] = 30
i = 3 → nums[3] = 40
```

**B：找到比 `num` 大的數**

```
if nums[i] > num:
```

例如：

```
num = 25
nums = [10, 20, 30, 40]
```

檢查：

```
10 > 25 → False
20 > 25 → False
30 > 25 → True  ← 找到了
```

找到之後印出訊息。

**D：找到後 `break`**

```
break
```

題目說：

> 找到一個比 `num` 大的數之後就停止搜尋。

所以一定需要 `break`。

---

### 最重要的是 C 的 `else`
```
for i in range(len(nums)):
    if nums[i] > num:
        ...
        break
else:
    ...
```
注意這個：
```
else:
```
是跟 **`for` 對齊**，不是跟 `if` 對齊。
這叫：
```
for ... else
```
它的意思是：
> **如果 `for` 正常跑完，而且沒有遇到 `break`，才執行 `else`。**
例如：
```
nums = [10, 20, 30]
num = 50
```
全部檢查：
```
10 > 50 → False
20 > 50 → False
30 > 50 → False
```
從頭到尾都沒有執行：
```
break
```
所以最後執行：
```
else:
    print("找不到")
```
### ⭐ 這題考試最重要的觀念
把它記成：
```
for ...:
    if 找到了:
        print("找到")
        break
else:
    print("找不到")
```
也就是：
**找到 → `break` → 不執行 `else`**
**沒找到 → 沒有 `break` → 執行 `else`**
所以最終答案：
> **✅ E → A → B → D → C**


## ##9 ----


完整程式：

```
product_no = ""               # (1)
parts = ""

while product_no != "":       # (2)
    valid = False             # (3)

    product_no = input("Enter product number (dd-dddd): ")
    parts = product_no.split('-')

    if len(parts) == 2:
        if len(parts[0]) == 2 and len(parts[1]) == 4:
            if parts[0].isdigit() and parts[1].isdigit():
                valid = True  # (4)

    print(valid)
```

這題的 `for...else` 是 Python 很常考的陷阱，尤其要注意 **`else` 是跟 `for` 對齊的，不是跟 `if` 對齊。**
這題主要考 **哨兵迴圈（Sentinel Loop）**、`while`、布林值，以及 `split()` / `isdigit()`。

正確答案是：

> **(1) A、(2) A、(3) A、(4) B**

也就是 **A、A、A、B**。


不過這裡有一個值得注意的地方：照圖片的選項與程式結構，**(1) 如果是 `product_no = ""`，那麼 `(2) while product_no != "":` 一開始就不會執行**。

所以如果題目的目的真的是「持續輸入，直到輸入空字串才停止」，合理的哨兵寫法應該是：
```
product_no = "sentinel"

while product_no != "":
```
也就是：
> **(1) B、(2) A、(3) A、(4) B**
### 為什麼？
一開始：
```
product_no = "sentinel"
```
目的只是讓第一次：
```
while product_no != "":
```
成立
因為：
```
"sentinel" != "" → True
```
所以進入迴圈，讓使用者輸入：
```
product_no = input(...)
```
如果使用者直接按 Enter：
```
product_no = ""
```
下一輪：
```
"" != "" → False
```
迴圈停止。

---

### `(3)` 為什麼是 `valid = False`？
每次輸入新的產品編號，都要先假設：
```
valid = False
```
然後一層一層檢查。
例如：
```
12-3456
```
先檢查：
```
len(parts) == 2
```
再檢查：
```
len(parts[0]) == 2
len(parts[1]) == 4
```
最後檢查：
```
parts[0].isdigit()
parts[1].isdigit()
```
全部通過後才：
```
valid = True
```
所以 `(4)` 是 **B**。
### 最後答案
依照「哨兵迴圈」的正確邏輯：
```
(1) B  product_no = "sentinel"
(2) A  while product_no != "":
(3) A  valid = False
(4) B  valid = True
```
> **✅ 答案：B、A、A、B**

for 正常結束

執行 else
```

所以最後一個字元 `"p"` 的索引不是 `6`，而是：
```

```

```
得到：
```

```

```

```

```

```

### `backward_name[length]` 在做什麼？

第一次：
```
length = 5
```
所
```

```
取得：
```

```
加入：
```
forward_name += "p"
```
接著：
```

```
變成 `4`。
下一輪：
```

```

|length|取得字元|forward_name|
|---|---|---|
|5|p|`"p"`|
|4|y|`"py"`|
|3|t|`"pyt"`|
|2|h|`"pyth"`|
|1|o|`"pytho"`|
|0|n|`"python"`|

當：
```
length = -1
```
判斷：
```
while length >= 0:
```
變成：
```
-1 >= 0 → False
```
迴圈結束。
## 這題最值得記的公式

如果字串：
```

```
長度：
```

```
最後一個索引：

```
len(text) - 1  # 5
```
所以：
> **長度是 N → 最後一個索引是 N - 1**

# ##CH5-5--
這題主要在考 **`if / elif / else` 的條件順序與縮排**。正確答案是：

**(1) A、(2) B、(3) C**

完整程式會是：

```
def ticket_fee(age, school):
    fee = 0

    if age >= 5 and school == True:       # (1) A
        fee = 60

    elif age >= 5 and school == False:    # (2) B

        if age <= 17:                     # (3) C
            fee = 120
        else:
            fee = 180

    return fee
```
### 為什麼這樣選？

先看題目的四個規則：

|條件|票價|
|---|---|
|5 歲以下|免費|
|≥ 5 歲，而且是學生|60 元|
|5～17 歲，而且不是學生|120 元|
|> 17 歲，而且不是學生|180 元|

關鍵是題目圖片中的**縮排**：
```
if ...:                 ← (1)
    fee = 60

elif ...:               ← (2)
    if ...:             ← (3)
        fee = 120
    else:
        fee = 180
```
所以 **(1) 和 (2) 是同一層級**，必須形成：
```
if ...
elif ...
```
而 **(3) 是放在 (2) 裡面的第二層判斷**。
因此：
```
# (1)
if age >= 5 and school == True:
```
表示「滿 5 歲而且是學生」→ 60 元。
接著：
```
# (2)
elif age >= 5 and school == False:
```
表示「滿 5 歲而且不是學生」，但這時還不知道要收 120 還是 180，所以繼續進入下一層：
```
# (3)
if age <= 17:
    fee = 120
else:
    fee = 180
```
例如：
```
age = 15, school = True
→ (1) 成立
→ 60 元

age = 15, school = False
→ (1) 不成立
→ (2) 成立
→ (3) age <= 17 成立
→ 120 元

age = 20, school = False
→ (2) 成立
→ (3) age <= 17 不成立
→ else
→ 180 元

age = 4
→ (1)、(2) 都不成立
→ fee 保持原來的 0
→ 免費
```
### ⭐ 這題真正的考點：縮排

你圖片上的紅字非常重要：
> **第 (2) 格與第 (1) 格是垂直對齊的，代表它們是同一個層級。**
所以結構是：
```
if (1)
│
├── fee = 60
│
elif (2)          ← 和 if 對齊
    │
    └── if (3)    ← 縮排，代表屬於 elif 裡面
        ├── fee = 120
        └── else
            └── fee = 180
```
考試看到這種「填程式片段」的題目，**先看縮排，再看條件**，通常會容易很多。

### 為什麼不能if + `if`？
例如：
```
if age >= 5 and school:
    fee = 60

if age >= 5:
    if age < 17:
        fee = 120
    else:
        fee = 180
```
假設：
```
age = 15
school = True
```
第一個 `if`：
```
age >= 5 and school
```
是 `True`：
```
fee = 60
```
但是！第二個 `if` **還是會繼續判斷**：
```
if age >= 5:   # True
```
接著：
```
if age < 17:   # True
    fee = 120
```
所以最後變成：
```
fee = 120
```
原本學生票的 `60` 被蓋掉了。

---

### 那為什麼不能直接用if + `else`？

如果寫：
```
if age >= 5 and school:
    fee = 60
else:
    if age < 17:
        fee = 120
    else:
        fee = 180
```
會出現另一個問題。
假設：
```
age = 3
school = False
```
第一個條件是 False，所以直接進入 `else`：
```
if age < 17:
    fee = 120
```
結果 **3 歲竟然收 120 元**。
但是原本程式：
```
elif age >= 5:
```
還會多檢查一次「是否滿 5 歲」，3 歲不符合，所以 `fee` 保持 `0`。
所以這題使用 `elif` 的關鍵原因是：

> **第一個條件不成立後，還不能直接決定票價，必須再判斷 `age >= 5`。**

而且一旦學生票 `fee = 60` 成立，就不希望後面的年齡票價再把它改掉。
那 if 縮排if 與if elif有什麼差別
有差，而且這是 Python 很重要的觀念。

### 為什麼不能`if` 裡面縮排一個 `if`：巢狀 if

```
if age >= 5:
    if age < 17:
        fee = 120
```
意思是：
> **第一關成立後，才有資格進入第二關判斷。**
例如 `age = 15`：
```
age >= 5  → True
    ↓
age < 17  → True
    ↓
fee = 120
```
如果 `age = 3`：
```
age >= 5 → False
    ↓
結束，裡面的 if 根本不會判斷
```
所以「縮排的 `if`」是**第二層條件**，它依賴外面的 `if`。

---

### ② `if` + `elif`：同一層的多選一

```
if age >= 5 and school:
    fee = 60
elif age >= 5:
    fee = 120
```

意思是：

> **第一個條件不成立，才換第二個條件試試看。**

例如：
```
age = 15
school = True
```
第一個成立：
```
age >= 5 and school → True
fee = 60

elif 不再判斷
```
如果：
```
age = 15
school = False
```
則：
```
第一個 if → False
       ↓
elif age >= 5 → True
       ↓
fee = 120
```

---
### 最重的差別

```
if 條件A:
    if 條件B:
        ...
```
是：
> **A 成立 → 再判斷 B**
而：
```
if 條件A:
    ...
elif 條件B:
    ...
```
是：
> **A 不成立 → 才判斷 B**
可以簡單記成：
**巢狀 `if` =「而且還要……」**
**`elif` =「不然的話，再看看……」**
所以你的原程式其實兩種都有：

```
if age >= 5 and school:       # 第一選擇
    fee = 60

elif age >= 5:                # 第一選擇失敗，改試第二選擇

    if age < 17:              # 第二選擇成立後，再進一步判斷
        fee = 120
    else:
        fee = 180
```

這裡的 `elif` 是**換一條路**；裡面縮排的 `if` 是**進入這條路之後，再做第二次判斷**。
# **對，你可以把筆記補完整成這樣，這樣四種情況就很清楚：**

|寫法|意思|判斷關係|
|---|---|---|
|`if` + `if`|兩個條件**各自獨立判斷**，兩個都可能執行|A 判斷完，B 也會判斷|
|`if` + `elif`|前面不成立，**才檢查下一個條件**|同一層，多選一|
|`if` + `else`|前面不成立，**直接執行 else**|二選一，`else` 沒有條件|
|`if` 裡縮排 `if`|**第一關成立後，才有資格進入第二關**|巢狀判斷，一關一關進去|

其中最容易搞混的是這兩個：
```
# if + elif
if A:
    ...
elif B:
    ...
```
意思是：
```
A 成立 → 執行 A → 不看 B
A 不成立 → 才判斷 B
```
但是巢狀 `if`：
```
if A:
    if B:
        ...
```
意思是：
```
A 成立
  ↓
才判斷 B
  ↓
B 成立才執行

A 不成立
  ↓
連 B 都不判斷
```
所以可以用一句口訣記：
> **`if + elif`：A 不成立，才看 B。**  
> **巢狀 `if`：A 成立，才看 B。**
這兩句非常適合當考試重點。
